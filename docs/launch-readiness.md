# Glance 官网发行准备

更新：2026-10-29。范围：备案与 Apple 开发者审核以外的上线准备。服务端、后台与官网已部署；macOS 源码已更新，客户端由用户构建并验收。

## 已完成

- [x] 商户退款 API 修正；Waffo 沙盒付款及全额退款回调验证。600 点入账、回收各一笔，测试账户余额恢复为 951；重复通知由回归测试覆盖。
- [x] CNY / USD / JPY / EUR / HKD 的服务端、后台及客户端支持。JPY 使用整数日元，其他币种使用分；CNY 走微信，其余币种走银行卡 / Apple Pay / Google Pay，避免向日元订单传入不支持的微信支付。

- [x] 测试订单不计入正式付费转化；测试授权不能跨入正式环境，正式退款不恢复旧测试授权。
- [x] 测试／正式私钥分别配置为 Worker Secrets。正式 webhook 公钥来自官方 npm SDK 0.27.0，与已安装 0.26.0 内置值一致；测试公钥与实际已验签的公钥一致。无需用户另外复制公钥。
- [x] Sparkle 2.10.1 接入、签名更新源、Debug/Release entitlement 分离、嵌套组件签名及打包公证脚本。线上 feed 已验签，但尚无正式更新包。
- [x] 官网价格显示支持、账户／团队／隐私政策与产品行为对齐；老内测版没有删除入口时可联系支持邮箱。
- [x] `spec.md`、计费配置说明与操作文档已更新。

## 当前支付状态

仍为 `WAFFO_ENVIRONMENT=test`、公开销售 `enabled=false`、`TEST_CHECKOUT_USER_ID=2`。不是正式收费状态。

正式商品配置模板位于 [`server/GlanceService/config/billing-production-v1.json`](../server/GlanceService/config/billing-production-v1.json)，模板也保持销售关闭。正式凭据和 webhook 已准备，但没有进行真实正式付款验收。切换时必须同时选择正式环境、正式商品映射，并移除测试购买例外；不要将正式商品 ID 绑定到沙盒。

测试与正式共用数据库；订单、统计及授权已按环境处理，并非整库隔离。内部测试账户的点数仍使用同一钱包。

## 待用户构建与验收

- [ ] 图片转换后的新图片进入结果展示区域并选中，能找到文件与再次操作。
- [ ] 各类 Widget：余额不足先充值；足够先确认费用；关闭弹窗不创建任务、不扣点；充值后不自动提交。
- [ ] 视频：按每 10 秒向上取整确认费用，失败全额退点。当前处理上限仍约 187.2 秒、50 MiB、24 段，30 分钟视频尚不支持，应在付费处理前拒绝。
- [ ] 五币种显示与沙盒支付返回；个人版开通、5 人版邀请／接受／移除／退出。付款需在 Waffo 测试页面手工完成；本轮仅自动创建并放弃 Pro 验证订单，未替用户支付 Pro。

- [ ] 检查更新菜单与首次权限体验；完成 Developer ID 签名、公证后，再验收实际更新安装。
