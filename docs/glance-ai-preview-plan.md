# Glance 修改方案与工期：AI 时代的 Preview

> **核心**：Glance 是 AI 时代的 Preview。看图看视频是主动作，看完不满意就地用 AI 改，改完用对比确认。
> 本方案中的每一项，都以「是否让 **看 → 改 → 对比** 这条主路径更顺」为准。
> 日期：2026-10-12。工期单位为「人天」（约 6 小时专注开发）。

## 1. 现状诊断：主路径断在哪里

| 环节 | 现状 | 问题 |
|---|---|---|
| **看** | Finder 打开、拖入、粘贴、Home 都能用，且不需要权限 | 首次启动强制弹出 Peek 的权限引导，每次启动都会再弹；没有「设为默认看图器」；没有 File > Open 这样的主菜单；Finder 打开的文件不进历史 |
| **改** | 工具栏的 Widget 按钮只会打开 Market | 跑 Widget 只能靠右键（Widgets 子菜单，3 次点击）；没装 Widget 时没有任何提示；跑之前不检查登录；「Remove Background」会跑第一个装上的 Widget，不管它是什么；本地工具（格式、base64、压缩、OCR）和 AI 工具分散在不同菜单里 |
| **等** | 源图有呼吸边框 | 没有文字和进度，也不能取消；任务进行中这张图的其他操作全被禁用 |
| **对比** | 结果会插到源图后面，并自动切过去 | 没有一键前后对比；Compare 按 index 配对，可能配错；结果文件按命令命名，原文件名丢了；点系统通知没反应；Task Center 打开结果时会丢掉原图；视频只有并排，没有滑杆 |

**可复用的现成模式**：压缩功能的 `insertCompressedImage`（`ImageInspectWindow.swift:2560`）已经完整做到「结果插在原图旁 → 并排对比 → toast 提示」，正是主路径要的样子，只是写死在压缩里。

## 2. 修改方案（按模块）

### M0 结构准备（1.5 人天）
- 机械拆分 `ImageInspectWindow.swift`（6.9k 行）和 `VideoCompareWindow.swift`（2.8k 行）中的辅助类型，挪到 `Inspect/`、`Video/` 目录，不改逻辑。M1–M3 都要改这两个文件，先拆可以降低出错风险。
- 删除死代码：`runWidgetButton`、`StatusBarController.createMenu`、`WidgetPlatformClient.review/promote`。

### M1 「改」入口清理（1 人天）
- **工具栏 Widget 按钮不变**（继续打开 Market）；跑 Widget 的入口是右键菜单，图片和视频都已有 Widgets 子菜单。
- 删除「Remove Background 跑第一个 Widget」和「Upscale 按名字猜」这两个隐藏入口。
- 右键菜单加一行「Widget 市场…」兜底，包括没有可用 Widget 的情况。
- 「运行前检查登录」移到 P3，和邀请码鉴权一起做（客户端现有的登录路由在服务端不存在）。

### M2 结果与对比衔接（3 人天）
- **保持现有逻辑**：结果成功后插到源图右边并直接展示，带 NEW 徽标。**不自动进入对比**，由用户自己决定。
- 用户点 Compare 或 Slider 时，如果当前是 Widget 结果，**自动和它的源图配对**（现在按 index 配对，可能配错）。
- 把 `insertCompressedImage` 里的插入逻辑抽成通用函数，让压缩、格式转换和 Widget 结果都用同一套插入规则（压缩保持现在进入对比的行为）。
- 结果文件命名改为 `原文件名.去水印.png`，避免互相覆盖，也能看出来源。
- 点系统通知 → 打开 Inspect，带上原图和结果，展示结果。
- Task Center 的「在 Inspect 中查看」→ 同时带上原图，方便用户自己进入对比。

### M3 等待体验（2 人天）
- Inspect 里显示文字状态：「正在去水印… 上传中 / 处理中 42%」，在 V2 spec 规定的左下角，自动淡出。
- **可以取消**：客户端加 cancel API，调用服务端已有的取消接口。
- 任务进行中，只禁用会冲突的操作；看图、缩放、本地工具照常可用。

### M4 看图器优先：首次启动零权限（4 人天）
- 首次启动直接打开 Home，不再弹权限引导。
- Peek 改为**主动开启**：在偏好设置或托盘里打开「Peek（选中文本秒开）」时，才弹出权限引导并说明为什么需要。
- 授权后立即启动热键监听，不再需要重启 App（修掉现有 bug）。
- Home 增加「设为默认看图器」按钮（`NSWorkspace.setDefaultApplication`，macOS 12+）。
- 加上 App 主菜单：File > Open（⌘O）、Edit > Paste（⌘V）。
- 托盘头部改成 Home + 最近打开；Peek 开关和权限收到「Peek」分组里；更新 About 文案，删掉「Hold Cmd+Shift and hover」这类过时说明。
- Finder 打开的文件也记入历史。

### M5 视频对比补齐（3 人天）
- 视频 Compare 按「源 ↔ 结果」配对。
- 新增**视频滑杆对比**（同步播放，复用 `ImageRevealView` 的交互）。
- 视频 Widget 结果的插入、配对和命名规则与 M2 一致。

### M6 把常用 Widget 做稳（3 人天）
- 预装目前已有的全部 Widget，新用户打开就能直接用，不必先去 Market。
- 官方 Worker 部署到 VPS 常驻（systemd）。
- 服务端：任务排队超时记为 `expired`，重试上限 3 次。
- 客户端：遵守 `pollAfterMs`；遇到 401/404/expired 立即停止，并给出可读的失败原因。

### M7 对外发布的前提（5 人天，另需等待 D-U-N-S）
- 后端真正鉴权：邀请码换设备 token，每人每天 20 个任务、全局每天 300 个（2.5 人天）。
- Developer ID 签名、公证、DMG、Sparkle 自动更新、Release 去掉 `get-task-allow`（2 人天）。
- 补齐英文缺失的 69 个 key，更新 README 和隐私说明（0.5 人天）。

### M8 主路径界面按 V2 设计落地（10 人天）
- Image Inspect（6 人天）和 Video Inspect（4 人天）按 Figma 落地：工具栏、状态栏、filmstrip 固定显示，inspector 280pt。
- 只做主路径涉及的界面，Market、Task Center 等其余界面冻结。

## 4. 不做的事（守住「保持小」）
- 不扩展开发者平台（审核、灰度、OAuth、CLI 冻结）。
- 不做积分和支付，等验证结果的付费意愿数据出来再说。
- 不改 Market、Task Center、History 等非主路径界面的视觉。
- builtin Widget 的 manifest 统一化（本地工具进 Market）推迟；本地工具暂时保持在右键和 More 菜单里。

## 5. 已确认的决定（2026-10-12）
1. Widget 结果成功后保持现有逻辑：直接展示结果，**不自动进入对比**，由用户决定。
2. 不新增需要 Figma 稿的界面：工具栏 Widget 按钮不变，跑 Widget 走右键菜单；取消「对比查看」提示条。

执行版任务清单：`docs/glance-ai-preview-tasks.md`。
