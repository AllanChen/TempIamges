# 账户与五人版

V1：多人版含购买者共 5 个独立账户，每个账户 1 台 Mac，点数独立。购买者获得一次性 Pro 点数赠送；邀请成员不重复发放购买赠点。

## 客户端入口

- Glance → 团队账户：购买者邀请、撤销邀请、移除成员；受邀者接受邀请码或退出团队。
- 邀请绑定指定邮箱，7 天有效。购买者手动私下分享；系统不发送邀请邮件。
- 邀请不预占名额；接受时由数据库原子检查总人数，并发也不能超过 5 人。
- 移除、退出或团队订单退款后，在线授权撤销。多人版离线凭证最多 24 小时。个人版最多 30 天。
- 个人版升级多人版按多人版全价购买；退回多人版订单时恢复仍有效的原个人版订单。

## 删除账户

Glance → 删除账户，输入完整账户邮箱并再次确认。未使用点数作废，不自动触发现金退款。应先处理退款申请。

存在运行中任务、待交付结果、待付款订单或待处理退款时拒绝删除。成功删除后立即撤销登录，匿名化用户个人资料并撤销 Pro、团队及设备授权。保留账务记录用于对账，不删除账本。

每 5 分钟的定时任务清理自有 R2 上传及结果，并清空任务内容、报价快照及结账链接。对象存储失败会保留队列重试；持续扫描 7 天以捕获删除时仍在途的上传。第三方服务的数据保留须遵循相应供应商政策，不声称已清除第三方存储。

## API 与迁移

全部接口要求当前用户认证：

- `GET /api/v2/account/team`
- `POST /api/v2/account/team/invites`，`{email}`
- `POST /api/v2/account/team/accept`，`{code}`
- `DELETE /api/v2/account/team/members/:userID`
- `DELETE /api/v2/account/team/invites/:id`
- `POST /api/v2/account/team/leave`
- `DELETE /api/v2/account`，`{email, confirm:"DELETE"}`

迁移 0020 添加成员及邀请码；0021 添加持久清理队列；0022 保留订单及引用、扩展五币种并记录支付环境。测试订单不计入正式支付转化报表。0023 使测试授权不能跨入正式环境，正式退款只恢复同环境的有效订单。
