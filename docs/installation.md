# Glance 安装指南

Glance 是 AI 时代的 Preview：看图看视频，不满意就地用 AI 改，改完对比确认。

## 安装

1. 下载 `Glance-<版本>.dmg`，双击打开。
2. 把 Glance 拖到 Applications 文件夹。
3. 在 Applications 里双击 Glance。

## 首次打开被拦截怎么办

内测版还没有经过 Apple 公证，macOS 第一次打开时会拦截，**这是正常的**，只需放行一次：

**macOS 15（Sequoia）及更新版本**
1. 双击 Glance，看到「无法打开」提示后点「完成」。
2. 打开 **系统设置 → 隐私与安全性**，往下滚到「安全性」。
3. 在「已阻止 Glance 打开」旁边点 **仍要打开**，输入密码确认。

**macOS 14 及更早版本**
- 在 Applications 里**右键 Glance → 打开**，在弹窗里再点一次「打开」即可。

放行一次之后，以后双击就能正常打开。

## 开始使用

- 直接打开图片或视频：在 Finder 里右键文件 → **打开方式 → Glance**。
- 想让它成为默认看图器：菜单栏 **Glance → 设为默认看图器…**。
- 选中两张图片一起打开，可以直接进入对比。
- 右键图片或视频，选择 **Widgets**，用 AI 处理（去水印、扩图等）；完成后结果会出现在原图旁边，点 **Compare** 或 **Slider** 对比效果。

Glance 作为普通 App 运行，有 Dock 图标，也有菜单栏图标。首次打开**不需要任何系统权限**。

## 可选：Peek（选中文本秒开预览）

在任意 App 里选中一段包含图片链接或文件路径的文字，按下热键（默认 Option + Space）就能预览。
这是可选功能，在 **偏好设置 → 启用 Peek** 里打开；打开时会引导你授予「辅助功能」权限。当前快捷键监听和选中文字读取均由辅助功能授权覆盖，「输入监控」无需额外授权；即使其系统列表里没有 Glance，也不应阻止 Peek 使用。

权限引导可以通过左上角关闭按钮、Esc、Command-W 或“继续”退出，不要求全部授权；跳过后下次启动不自动重弹。未授权时仍可从文件或 Home 使用 Glance，只是对应的 Peek／受保护文件访问功能受限。「完全磁盘访问」始终可选。需要时可从权限设置入口重新打开引导。

点击「Open Settings」会先请求对应权限，再跳转系统设置。输入监控按钮使用 IOHIDRequestAccess 显式请求；辅助功能已授权时，该项会显示“无需单独授权”。如果列表中仍没有 Glance，点引导里的 **「列表中找不到 Glance？」**：

1. 在「系统设置 → 隐私与安全」打开对应权限分类，点击 **＋**。
2. 可用「在访达中显示 Glance」找到当前 App，或用「复制 App 路径」，在选择窗口按 **Command-Shift-G** 后粘贴路径。
3. 添加 Glance 并打开开关。若系统要求退出并重新打开，按提示操作。

请先把 DMG 中的 Glance 拖到 Applications，再从 Applications 启动和授权。旧版本的 Glance 条目失效时，可移除旧条目再添加当前 App。

## 预览窗口最小尺寸

Peek 浮动预览下限为 400×320 点，并修正过小的历史窗口尺寸。图片 Inspect 的内容区域下限为 560×360 点，视频 Inspect 为 560×488 点，打开、切换素材和手动缩小时均保留可操作空间。小屏幕以实际可用区域为上限；极窄或极矮素材等比显示，必要时留边，不拉伸素材。
