安装

  1. 下载 Glance-1.0.0-beta.1.dmg，双击打开。
  2. 把 Glance 拖到「应用程序」文件夹。
  3. 在「应用程序」里双击 Glance。

首次打开被拦截怎么办

内测版还没有经过 Apple 公证，macOS 第一次打开时会拦截，这是正常的，只需放行一次。

macOS 15（Sequoia）及更新版本

  1. 双击 Glance，看到「无法打开」提示后点「完成」。
  2. 打开「系统设置 → 隐私与安全性」，往下滚到「安全性」。
  3. 在「已阻止 Glance 打开」旁边点「仍要打开」，输入密码确认。

macOS 14 及更早版本

在「应用程序」里右键 Glance，选择「打开」，在弹窗里再点一次「打开」。

放行一次之后，以后双击就能正常打开。

开始使用

  • 直接打开图片或视频：在 Finder 里右键文件，选择「打开方式 → Glance」。
  • 设为默认看图器：菜单栏选择「Glance → 设为默认看图器…」。
  • 选中两张图片一起打开，直接进入对比。
  • 右键图片或视频，选择「Widgets」用 AI 处理。完成后结果出现在原图旁边，点 Compare 或 Slider 对比效果。

Glance 作为普通 App 运行，有 Dock 图标，也有菜单栏图标。首次打开不需要任何系统权限，也不需要账户。首次启动即开始 14 天完整试用。

可选：Peek（选中文本秒开预览）

在任意 App 里选中一段包含图片链接或文件路径的文字，按下热键（默认 Option + Space）就能预览。这是可选功能，在「偏好设置 → 启用 Peek」里打开。打开时会引导你授予「辅助功能」和「输入监控」两项权限，这两项权限只用于识别热键和读取你选中的文字。选中的文字不会发送到 Glance 服务器；如果是网络链接，Glance 会直接从该网站加载预览。

反馈与问题

发送邮件到 support@mcreator.ai。遇到问题时，最好附上截图或日志文件 ~/Library/Application Support/Glance/app.log。

卸载

退出 Glance，把它从「应用程序」拖到废纸篓。如需同时删除本地设置与日志，删除 ~/Library/Application Support/Glance。账户与点数保存在云端，如需删除账户，请发邮件给我们。

Install

  1. Download Glance-1.0.0-beta.1.dmg and double-click it.
  2. Drag Glance into the Applications folder.
  3. Double-click Glance in Applications.

If macOS blocks the first launch

The beta is not yet notarized by Apple, so macOS blocks it the first time. This is expected; allow it once.

macOS 15 (Sequoia) and later

  1. Double-click Glance. When you see “cannot be opened”, click Done.
  2. Open System Settings → Privacy & Security and scroll down to Security.
  3. Next to “Glance was blocked”, click Open Anyway and confirm with your password.

macOS 14 and earlier

Right-click Glance in Applications, choose Open, then click Open again in the dialog.

After that, Glance opens normally with a double-click.

Getting started

  • Open an image or video: right-click it in Finder and choose Open With → Glance.
  • Make Glance your default viewer from the menu bar: Glance → Set as Default Viewer….
  • Select two images and open them together to compare.
  • Right-click an image or video and choose Widgets to process it with AI. The result appears next to the original; click Compare or Slider to compare.

Glance runs as a regular app with a Dock icon and a menu bar icon. It needs no system permissions and no account on first launch. The 14-day full trial starts on first launch.

Optional: Peek

Select text containing an image link or file path in any app and press the hotkey (Option + Space by default) to preview it. Peek is optional; turn it on in Preferences → Enable Peek. Glance then asks for Accessibility and Input Monitoring permissions, which are used only to detect the hotkey and read the text you selected. The text is never sent to Glance's servers; for a web link, Glance loads the preview directly from that website.

Feedback and help

Email support@mcreator.ai. When reporting a problem, a screenshot or the log file ~/Library/Application Support/Glance/app.log helps a lot.

Uninstall

Quit Glance and drag it from Applications to the Trash. To remove local settings and logs too, delete ~/Library/Application Support/Glance. Your account and credits live in the cloud; email us to delete your account.
