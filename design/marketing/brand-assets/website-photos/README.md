# 官网动态展示照片收集

把新照片直接放在这个目录即可，无需先分类或统一文件名。

本次用途：将独立 Figma 官网首页上方的首屏，以及「查看」「就地修改」「对比」中的静态产品展示改成约 3–4 段带文字说明的 GIF／视频。使用更多不同人物，避免各区域重复使用现有三位人物。首页下方 Widget 展示区不再新增演示，九项 Pro 演示暂不加入。

## 建议提供

- 先放 6–10 张不同人物的照片，男女均可，半身、全身和近景可以混合。
- JPG、PNG、WebP 原图均可，建议长边至少 2000 像素，不必事先裁剪、压缩或加字。
- 如有同一张照片的实际处理结果，一并放入，可用 `人物名-before.jpg` 与 `人物名-after.png` 配对；只有原图也可以。
- 可以附一个 `notes.txt` 标注特别想展示的效果或人物。没有说明时，由设计环节挑选与分配。

保留照片原件；后续剪裁副本、封面、GIF 与 MP4 输出放在对应官网设计或宣传视频目录。
