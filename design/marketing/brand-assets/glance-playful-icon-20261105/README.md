# Glance「探头预览窗」图标概念

使用 [design-playful-app-icons](https://github.com/chunkithwang/design-playful-app-icons) 的文本设计流程，由内置 imagegen 生成并进行一次结构修订。

## 交付

- `glance-peek-window.png`：生成原图，1254 × 1254，RGB，不透明。
- `glance-peek-window-1024.png`：1024 × 1024 缩放版。
- `prompt.txt`：完整初始提示词，包括负面约束。
- `refinement-prompt.txt`：最终修订提示词，结合初稿作为图像输入。

## 设计规格

- Lane：soft_3d_object_character，柔和立体物件角色。
- 隐喻：内容卡片 + 即时探出预览 + 好奇。
- 唯一记忆点：从预览窗上缘探头的卡片。
- 配色目标：钴蓝 #1865EE、暖白 #F8F6F5、深海军蓝 #1C212C；生成图包含材质明暗变化，并非逐像素严格限定色值。
- 材质与光线：统一柔软塑料、宽圆角、左上方柔光、短漫射阴影。
- 图层关系：蓝色背景 → 阴影 → 窗口后缘与暗部 → 内容卡片 → 窗口前缘。当前交付是合并位图。
- 满版方形背景，无预烘焙外部圆角，关键五官保留约 12% 边距。

## 质量报告

人工视觉评分 84/100：产品含义 16/20，轮廓 17/20，小尺寸 18/20，色彩对比 14/15，风格一致性 10/10，原创性 8/10，平台就绪度 1/5。原创性评分不是商标检索结论。

实际查看了 1024、180、60、32 px 缩略图：1024 px 光影与边缘连贯；180 px 卡片与窗口层次明确；60 px 两只眼睛和窗口可辨；32 px 仍能识别角色与窗口，但卡片的文件属性较弱，带有小幽灵的联想。

当前状态为可评审概念图，未替换应用资源。尚未做独立灰度/纯黑轮廓测试或 macOS 浅深背景下的图标适配；正式使用前需要按 macOS 资源流程处理外轮廓与多尺寸导出，并验证色彩配置。未启动 Glance，未构建应用。
