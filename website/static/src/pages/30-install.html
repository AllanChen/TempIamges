首次打开

Glance 已通过 Apple 公证。第一次打开时，macOS 会提示它是从互联网下载的 App，点「打开」即可。

如果提示无法打开，请先确认已把 Glance 拖进「应用程序」并从那里打开，不要直接在 DMG 窗口里运行；也可以用上方的 SHA-256 核对下载文件是否完整。

开始使用

  • 直接打开图片或视频：在 Finder 里右键文件，选择「打开方式 → Glance」。
  • 设为默认看图器：菜单栏选择「Glance → 设为默认看图器…」。
  • 选中两张图片一起打开，直接进入对比。
  • 第一次用 AI 改图：右键图片，选择「Widgets → Widget 市场…」，安装一个 Widget（例如人物背景分离，每次 20 点）。运行时按提示用 Google 或邮箱验证码登录，新账户送 100 点。完成后结果出现在原图旁边，点 Compare 或 Slider 对比效果。

Glance 作为普通 App 运行，有 Dock 图标，也有菜单栏图标。首次打开不需要任何系统权限，也不需要账户。首次启动即开始 14 天完整试用。

可选：Peek（选中文本秒开预览）

在任意 App 里选中一段包含图片链接或文件路径的文字，按下热键（默认 Option + Space）就能预览；没有选中文字时，Peek 会预览剪贴板内容。这是可选功能，默认关闭，在「偏好设置 → 启用 Peek」里打开。

打开 Peek 后，Glance 会引导你授予「辅助功能」权限，它只用于识别热键和读取你选中的文字。已授予「辅助功能」时，「输入监控」无需单独授权。「完全磁盘访问」是可选项，只在打开受系统保护的文件时需要。你可以跳过权限设置，查看图片和视频不受影响。

选中的文字不会发送到 Glance 服务器；如果是网络链接，Glance 会直接从该网站加载预览。

Install

  1. Download Glance-{{VERSION}}.dmg and double-click it.
  2. Drag Glance into the Applications folder.
  3. Double-click Glance in Applications.

If macOS blocks the first launch

This build is not yet notarized by Apple, so macOS blocks it the first time. This is expected; allow it once.

macOS 15 (Sequoia) and later

  1. Double-click Glance. When you see “cannot be opened”, click Done.
  2. Open System Settings → Privacy & Security and scroll down to Security.
  3. Next to “Glance was blocked”, click Open Anyway and confirm with your password.

macOS 14 and earlier

Right-click Glance in Applications, choose Open, then click Open again in the dialog.

After that, Glance opens normally with a double-click.

First launch

Glance is notarized by Apple. The first time you open it, macOS notes that it was downloaded from the internet; click Open.

If macOS says it cannot be opened, make sure you dragged Glance into Applications and opened it from there, not from the DMG window. You can also compare the download with the SHA-256 above.

Getting started

  • Open an image or video: right-click it in Finder and choose Open With → Glance.
  • Make Glance your default viewer from the menu bar: Glance → Set as Default Viewer….
  • Select two images and open them together to compare.
  • Your first AI fix: right-click an image, choose Widgets → Widget Market…, and install a Widget such as Background Remover Pro (20 credits per run). Run it and sign in with Google or an email code when asked; new accounts get 100 credits. The result appears next to the original; click Compare or Slider to compare.

Glance runs as a regular app with a Dock icon and a menu bar icon. It needs no system permissions and no account on first launch. The 14-day full trial starts on first launch.

Optional: Peek

Select text containing an image link or file path in any app and press the hotkey (Option + Space by default) to preview it. With no text selected, Peek previews the clipboard. Peek is optional and off by default; turn it on in Preferences → Enable Peek.

When you turn Peek on, Glance guides you to grant Accessibility, which is used only to detect the hotkey and read the text you selected. With Accessibility granted, Input Monitoring needs no separate grant. Full Disk Access is optional and only needed to open files macOS protects. You can skip permission setup; viewing images and videos is unaffected.

The text is never sent to Glance's servers; for a web link, Glance loads the preview directly from that website.
