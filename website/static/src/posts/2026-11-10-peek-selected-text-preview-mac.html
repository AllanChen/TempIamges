You see a path like ~/Downloads/hero-v2.png in a chat, a terminal or a document, and you want to know what the file looks like. Normally that means copying the path, opening Finder, pressing Shift-Command-G and pasting it. With Peek in Glance Preview, you select the text and press Option + Space, and the file opens in a preview without leaving the app you are in. This is part 3 of the Glance tutorial series; if Glance is not installed yet, start with Getting started with Glance on Mac.

What Peek can open

Peek reads the text you selected and looks for an image link or a file path in it, such as an https:// link, an absolute path or a ~/ path. A full path is the most reliable way to point Peek at a local file.

Glance previews images (JPEG, PNG, HEIC/HEIF, WebP, GIF, BMP and TIFF) and videos (MP4, MOV, M4V, WebM, MKV and AVI).

Peek is included in the free version of Glance; see the plan table on the Pricing page.

Step 1: Turn on Peek

Peek is optional and off by default, because it needs a system permission to read what you select.

  1. Open Glance's Preferences and turn on Peek.
  2. Glance asks for two permissions: Input Monitoring to detect the hotkey, and Accessibility to read the text you selected. Grant both in System Settings → Privacy & Security when prompted.

You can skip permission setup entirely; viewing images and videos in Glance works without it.

Step 2: Select text and press Option + Space

  1. In any app, select text that contains an image link or a file path.
  2. Press Option + Space, the default hotkey.
  3. The preview opens without leaving the app you are working in.

If no text is selected, Peek previews what is on the clipboard instead. That helps in apps that do not expose selected text: copy the text with Command-C, then press the hotkey.

Step 3: Open it in the full window when you need more

Peek is for a quick look. To zoom to 100%, compare two images or run an AI Widget, open the image in the full Glance window; the AI tools live there.

Where Peek saves the most time

  • AI chats and coding assistants: tools that write files often answer with a path like ~/project/output/banner_2x.png. Select it and press Option + Space to check the image before you continue.
  • Terminal output: after a script writes an image, select its path and look at it without opening Finder.
  • Logs, docs and tickets: a screenshot path in a bug report or an image link in a doc opens without switching to Finder or a browser.

When an image needs a fix, open it in the full window and use an AI Widget from the right-click menu. Part 2, Glance Widget Market and credits, shows how to install Widgets and what each costs.

Privacy

The selected text is read on your Mac to find a link or path, and it is not sent to Glance's servers. For a web link, Glance loads the preview directly from that website. Preferences, local history and the app log are stored on your Mac in ~/Library/Application Support/Glance/. See the Privacy policy for details.

If Peek does not open

  • Nothing happens: check that Peek is on in Preferences and that Glance is enabled under both Accessibility and Input Monitoring in System Settings → Privacy & Security.
  • The selection is not picked up: some apps do not expose selected text to macOS. Copy the text with Command-C and press the hotkey with nothing selected; Peek uses the clipboard.
  • A file in a protected folder does not open: use the full path, or grant the optional Full Disk Access permission, which is needed just for files macOS protects.
  • Still stuck: send a direct message on X to {{SUPPORT_X}}; the log file ~/Library/Application Support/Glance/app.log helps.

FAQ

How do I preview a file path from selected text on a Mac?

Quick Look in macOS works on files selected in Finder, not on paths in text. With Glance Preview, turn on Peek in Preferences, select the path in any app and press Option + Space; the file opens in a preview without opening Finder.

Which permission does Peek need?

Input Monitoring and Accessibility. Input Monitoring detects the hotkey, Accessibility reads the selected text. Full Disk Access is optional and helps with files in protected folders. Viewing images without Peek needs no permissions.

What is the Peek hotkey?

Option + Space by default. Peek is off until you turn it on in Preferences.

What if no text is selected?

Peek previews the clipboard instead, so you can copy a path and press the hotkey.

Does Peek send my selected text anywhere?

No. The text is read on your Mac. Web link previews load directly from the website.

Is Peek free?

Yes. Peek and history are included in the free version; AI Widgets use credits.
