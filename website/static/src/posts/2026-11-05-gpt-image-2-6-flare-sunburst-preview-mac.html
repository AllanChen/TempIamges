OpenAI released Images 2.6 on 4 November 2026 in ChatGPT, Codex and the API. In the API it ships as two models, GPT Image 2.6 Flare and GPT Image 2.6 Sunburst. Flare is built for fast iteration; Sunburst for detail and edit consistency. This post summarises what OpenAI documents about both, shows a fair way to test them, and walks through reviewing the downloads on a Mac with Glance Preview — including one-click fixes when a result is almost right.

What Images 2.6 adds

Per OpenAI's Introducing Images 2.6 post and the image prompting guide (read 2026-11-05):

  • Faster generation. OpenAI says Images 2.6 generates images about 50% faster than before. With quality set to low, Flare can return an image in as little as about six seconds.
  • GIF animation. ChatGPT Images 2.6 and the Image API can produce looping GIFs from a prompt (API: output_format=gif on generations).
  • Transparent backgrounds and SVG. Both 2.6 models support transparent backgrounds. API generations can also export SVG for logos and flat graphics.
  • More edit control. Markup-guided edits (already in ChatGPT) reach the API; a new complexity parameter (low / medium / high) controls how much planning the model does before rendering.
  • Availability. Images 2.6 is in ChatGPT and Codex on all subscription tiers (desktop, mobile, web). Flare and Sunburst are the API model IDs.

Glance Preview does not run GPT Image 2.6 and does not generate images from text. The workflow below is: create or edit outside Glance, download the files, then preview and optionally fix them on your Mac.

How to run a fair Flare vs Sunburst test

  1. Keep everything the same except the model. Same prompt, same reference images, same size, same quality and complexity. OpenAI notes that the same quality label does not guarantee the same look or speed across models — compare the pictures, not the settings.
  2. Make a few outputs per model (or a few Images 2.6 runs in ChatGPT if you are not on the API). One image each can mislead; a handful shows the pattern.
  3. Name the files clearly, for example poster-flare-1.png and poster-sunburst-1.png, and save them to one folder on your Mac. For transparent PNG or WebP, keep the alpha channel when you download. For GIFs, save the .gif as returned.
  4. Review matched pairs side by side as below, and note which run wins on the details you care about.

Preview and compare the downloads on your Mac

You can open both files in Preview and arrange two windows. That works, but matching zoom and pan is fiddly. Glance Preview is a beta image viewer for Apple silicon Macs that puts both images in one window:

  1. Open both images. In Finder, select the Flare and Sunburst files and open them together with Glance (Open With → Glance). If one is already open, drag the other into the window. You can also select a path or image link in another app and use Peek (optional; off by default) to preview, then open the full window when you want Compare or Widgets.
  2. Choose Compare in the toolbar for a side-by-side view. Useful for framing, colour and overall look.
  3. Choose Slider and drag the divider across the same spot. Useful for small text, hands, edges and textures.
  4. Transparent PNG. Check the cut-out against a busy background or another layer. If the model left a background you do not want, you can re-generate with background=transparent, or run Background Remover Pro in Glance (below).
  5. GIF. Open the downloaded GIF in Glance Preview to see how the loop looks as a file on your Mac. For a frame-by-frame A/B of two still renders, export matching frames (or use PNG/WebP outputs) and use Compare or Slider on those stills.
  6. Zoom into details before you decide. Comparing is free viewing: no account, no credits, and your files are not changed.

The compare two images guide covers both views in more detail.

What to look at closely

  • Text in the image: signs, labels and posters — one wrong letter can ruin the asset.
  • Faces, hands and brand marks, and whether a subject stayed the same after an edit.
  • Fine materials and edges: fabric, glass, hair and thin lines.
  • Edits to a reference image: check that what you asked to keep really stayed put (markup helps pinpoint changes in ChatGPT and the API).
  • GIF loops: whether the motion returns cleanly to the opening frame and whether brand details stay consistent across frames.

So which should you use?

  • Lots of drafts and quick iterations: start with Flare (or fast Images 2.6 runs in ChatGPT), as OpenAI suggests when speed matters.
  • Demanding quality, precise edits or brand-consistent revisions: start with Sunburst, then check whether Flare gets close enough on the same prompt.
  • Motion or logo-style assets: try GIF or SVG where OpenAI documents them, then inspect the download on your Mac before you ship it.
  • Either way: decide by looking at matched outputs side by side, not by the model name alone.

FAQ

What is the difference between GPT Image 2.6 Flare and Sunburst?

Per OpenAI, Flare is the smaller, speed-oriented model (about six seconds possible at low quality). Sunburst is the base model for higher detail and more consistent edits at medium or high quality. Both generate and edit images and support transparent backgrounds; API generations also support GIF and SVG.

Is Images 2.6 available in ChatGPT?

Yes. OpenAI says Images 2.6 is available globally in ChatGPT and Codex across all subscription tiers on desktop, mobile and web. Flare and Sunburst are the API model names.

Can GPT Image 2.6 make GIFs and transparent PNGs?

Yes, according to OpenAI's docs: ChatGPT Images 2.6 can create GIFs, and the API supports output_format=gif on generations plus background=transparent for PNG/WebP (and SVG). The image edit endpoint does not output GIF or SVG.

How do I compare two AI images side by side on a Mac?

Open both files in Glance Preview and choose Compare for side by side or Slider to wipe between them at the same spot. You can also place two Preview windows next to each other.

Can Glance Preview generate images with GPT Image 2.6?

No. Glance Preview is a viewer with one-click cloud AI tools for an existing image, such as background removal, upscaling and expanding. It does not generate images from text and does not call GPT Image 2.6.

Is comparing images in Glance Preview free?

Yes. Viewing and comparing images is free, needs no account and uses no credits. Credits are used by cloud AI Widgets.
