Glance Preview (glancepreview.com) is an image and video viewer for Apple silicon Macs: open an image, use a cloud AI Widget when it needs a change, then compare the result with the original. It is developed by Allan. Viewing and image comparison are free; cloud AI Widgets require an account and credits.

What can you do with Glance Preview?

The workflow starts with a file you already have. Open a photo from Finder with Glance, zoom in to inspect it and browse nearby images. To change it, install a suitable tool from Widget Market, then open the image’s right-click Widgets menu. After processing, inspect the result beside the source with Compare, or move the Slider divider across the images to check details.

For example, use Background Remover Pro for a cut-out, Upscale for a larger image, or Expand Image for more room around the subject. Look at hair, text, edges and areas you wanted to preserve before keeping an AI result. Results vary; a generated edit is not a guarantee of accurate detail.

You can also compare two existing image files without running a Widget. Opening a local image for comparison does not require an AI upload.

Which “Glance” app are you looking for?

Several unrelated Mac apps use the name Glance. Check the website or repository before following installation instructions:

  • Glance Preview — glancepreview.com: this image/video viewer with cloud AI editing and image comparison. Its download is on the official installation page. The MenuBarApps listing points to the same product.
  • Glance - Quick Look Code Files: a separate App Store app for file previews including source code and Markdown.
  • chamburr/glance: a Quick Look plugin, forked from samuelmeuli/glance. Its Homebrew command installs that plugin, not Glance Preview.
  • Glance: Face Unlock for Mac: a separate face-unlock project.
  • Glance - Prevent Eye Strain: a separate app for eye-break reminders.
  • Glance (glance.md): a separate Markdown editor for Mac. Reading .md files is free and its Pro license is a one-time US$9.99 purchase. It is not an image viewer.

Those names do not identify editions or plugins of Glance Preview. Their installation instructions and system requirements should not be applied to this app.

Free viewing, paid local tools and cloud credits

Viewing and comparing images are free. Glance Pro covers paid local tools such as converting, compressing and exporting. The Personal plan is US$9.99 as a one-time purchase for one Mac. Cloud AI processing has a separate credit balance: new accounts receive 100 credits, and a 600-credit pack is US$2.99. See current pricing for plan details.

  • Background Remover Pro: 20 credits per run.
  • Upscale, Expand Image, Redraw & Reframe and Remove Objects: 30 credits per run each.

These names and amounts were checked against the public catalog on 10 November 2026. AI Widgets upload the selected image for cloud processing and need an internet connection. Check the displayed cost before running one; see AI model disclosure for processing providers. Glance Preview is not an entirely offline AI editor.

Download and Mac requirements

The current download is version 1.0.2 for Apple silicon, requiring macOS 12.3 or later. It is notarized by Apple, so launching it just asks you to click Open. Follow the getting-started guide and the current installation page. This guide uses English button names; check the language options in your installed version.

FAQ

What is Glance Preview?

Glance Preview is Allan’s image and video viewer at glancepreview.com for Apple silicon Macs. It combines free viewing and image comparison with optional cloud AI Widgets that use credits.

Is Glance Preview the Glance Quick Look plugin?

No. Glance Preview at glancepreview.com is a separate product from Glance - Quick Look Code Files and the chamburr/glance Quick Look plugin. Use Glance Preview’s own installation page for its download.

Is Glance Preview free?

Viewing and image comparison are free. Pro local tools and cloud AI credits are separate paid options. New accounts receive 100 credits.

Does Glance Preview edit images offline?

Its AI Widgets process selected images in the cloud and require a login, internet access and credits. Local image viewing and comparison do not need an AI run.

Can I compare an AI result with the original?

Yes. Compare shows two images side by side; Slider lets you move a divider across them. Check the result before keeping it, because AI edits can change details you wanted to preserve.
