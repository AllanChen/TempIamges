Choose using a file you already have

Suppose a client sends a ZIP containing three product photos. If the question is “Did they send the back view?”, check the names and thumbnails with Folder Preview. If the same job includes a README and a WebM clip, Unfold covers both in Finder. For a code review, the extension matters more than the project name. Peek can find a line in supported source files, but a folder full of TypeScript calls for a tool that explicitly lists .ts, such as Unfold.

If the question is “Did removing the background cut into the bottle cap?”, open the photo in Glance Preview. Install Background Remover Pro from Widget Market, sign in and run it from the image’s Widgets menu. One run uses 20 credits. Move the Slider across the rim to inspect the cut-out. If the client supplied both images, skip the Widget and compare the pair locally for free.

FAQ

Which tool changes what I see when I press Space in Finder?

Folder Preview and Unfold extend Finder’s Quick Look for the file types they support. Glance Preview opens images and videos in its own window. Use it to compare two files locally or run a cloud AI edit. If the file path is written in a chat message, select the path and use Peek in Glance Preview (Option + Space).

Which option should I choose for a Mac running macOS 13?

For archive contents, Folder Preview lists macOS 12 or later. Unfold requires 15.6 or later. For photo comparison, Glance Preview supports macOS 13 on Apple silicon.

Which “Glance” should I download?

For code previews in Finder, look for Glance - Quick Look Code Files on the Mac App Store. For photo edits and side-by-side review, get Glance Preview from glancepreview.com.

Can I check an edit if the original must stay on my Mac?

Yes. Open the original and the edited file in Glance Preview and compare them locally. Running Background Remover Pro sends the selected image to the cloud.
