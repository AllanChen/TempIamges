Most image previews stop at looking. You open a photo, notice the background is messy or the image is too small, and then you leave the preview to fix it somewhere else. An AI image preview keeps the look instant and lets you fix what you see in the same window, then shows you whether the fix was worth keeping. This post explains how that works in Glance Preview, a beta image viewer for Apple silicon Macs, and where it falls short.

This post is about AI tools for images you preview, not Adobe Illustrator (.ai) files.

The loop in three steps

  1. Look. Open the image from Finder, or from a path or link you select in any app.
  2. Fix. Right-click the image and run a one-click AI tool, such as removing the background or upscaling.
  3. Check. The result appears next to the original. Click Compare for side by side, or Slider to wipe between the two.

Look: open the image fast

From Finder. Right-click an image and choose Open With > Glance. To open every image this way, set Glance as your default viewer from its menu bar icon. Viewing needs no account.

From selected text. Peek previews an image path or link without leaving the app you are in: select the text and press Option + Space. Peek is off by default. Turning it on in Preferences asks for Accessibility and Input Monitoring permissions. The AI tools live in the full image window, so open the image there to use them.

Fix: one-click AI tools from the right-click menu

Right-click the image and choose Widgets. Each tool shows its credit cost before you run it. The initial cloud run asks you to sign in with Google or an email code, and new accounts start with 100 credits. Tools run in the cloud in the background, so you can keep looking at other images while a task runs. If the tool isn't in your Widgets menu yet, add it from the Widget Market (the Widget button in the toolbar).

Each tool does one job with one click. None of them takes a free-form text prompt, so if you need to describe an edit in your own words, a prompt-based image editor is the right tool for that.

Check: compare the AI result with the original

When a tool finishes, the result is saved as a new file and placed next to the original in the same window; your original is not changed. Click Compare to see both side by side, or Slider to drag a divider across the pair.

Checking matters most for the generative tools. Generative tools such as Upscale create new image content, so they can invent detail that was not in your picture. Look at faces, text and edges at full size before you keep a result.

Glance Preview compared with Preview and Quick Look

macOS already has Preview and Quick Look. They are built in, free, and a good fit for plain viewing, and Preview can remove a background on recent macOS versions (see Apple's Preview guide). What Glance Preview adds is a menu of cloud AI tools on the image you are looking at, and a side-by-side or slider check of the result against the original in the same window. If all you need is to look at images, the built-in tools may be all you need.

Honest limits

  • Cloud, not on-device. Every AI tool uploads the image to Glance for processing and needs an internet connection. Viewing and comparing stay on your Mac.
  • Credits and sign-in. AI tools cost credits and need an account. In-app purchases are not open during the beta. If a task fails on Glance's side, the credits are returned, as described on the Pricing page.
  • Beta. Apple silicon Macs, macOS 12.3 or later. The beta is not notarized by Apple yet, so macOS asks you to allow it once; the install page has the steps.
  • Your images. Use watermark removal just on images you own or have permission to edit. See the acceptable use policy.

Try it on one image

A good test is a product photo with a busy background: open it in Glance Preview, run Background Remover Pro, and drag the Slider across the edges. The step-by-step version is in Remove an image background on Mac.

FAQ

What is an AI image preview on Mac?

It is an image viewer that lets you run AI fixes, such as background removal or upscaling, on the image you are looking at, and then compare the result with the original without leaving the window. Glance Preview works this way.

Can I edit an image with a text prompt in Glance Preview?

Not today. Its AI tools are one-click: each does one job, and none takes a free-form prompt.

Do the AI tools run on my Mac?

No. They run in the cloud, so the image is uploaded to Glance for processing. Viewing and comparing images stay on your Mac.

How much do the AI tools cost?

They use credits: 20 or 30 per run at the time of writing, and new accounts start with 100. In-app purchases are not open during the beta.

Do I need an account to view images?

No. An account is needed just for the cloud AI tools.
