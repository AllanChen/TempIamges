When you open an image in Glance Preview, it opens in the full image window. This is where you look closely at a picture, read its details, copy text out of it, grab a frame or screenshot, compare it with another file, and run AI Widgets. This tour walks through what is in that window and which parts are free.

Open an image

  • Right-click an image or video in Finder and choose Open With → Glance, or set Glance as your default viewer.
  • Drag a file into the window.
  • Select two images and open them together to go straight to a comparison.

Viewing needs no account and no Pro license. Glance reads PNG, JPEG, HEIC, WebP, AVIF, GIF, SVG, TIFF and more, plus MP4, MOV, M4V, WebM, MKV and AVI video.

Look closely: zoom, pan and browse

  1. Zoom in and pan across the image to check edges, text and texture at full size.
  2. Browse the other images in the same folder without going back to Finder.
  3. Rotate and flip affect the display, not the file.
  4. Pin the window on top if you want to keep it next to another app.

Read the details with image info

Glance can show information about the current image, which helps when you need the size or format before you send a file on. Viewing image info is part of the free version.

Copy text from an image

Glance recognizes the text in an open image on your Mac. Drag across the text and press Command-C to copy it. For the full result, open Tools → Recognize Text. The image is not uploaded, and this needs no Pro or credits. See Copy text from an image on Mac for the details.

Capture a screenshot or a video frame

Capture lets you grab part of the screen, or play a video and stop on any frame, then crop it in the capture editor and save or copy it. Saving and copying a capture is free.

Compare two images

Choose Compare in the toolbar to see an original and a changed version side by side, or Slider to drag a divider across them. This is the step to use after an AI Widget finishes, to check faces, edges and text before you keep the result. Comparison is free; see Compare images on Mac.

Run an AI Widget

Right-click the image and choose Widgets to run a one-click cloud tool such as Background Remover Pro. Widgets use credits, and each one shows its cost before you run it. The result is saved as a new file; your original stays as it was. See the getting started guide for the full loop.

Local tools that need Pro

Some local tools are in Pro, and they are available during the trial too. They run on your Mac and nothing is uploaded:

  • Format conversion and compression.
  • Export, Save As and copy image.
  • Rotate, flip, crop and markup saved back to the file.
  • Base64 tools.

Pro is a one-time purchase with free updates after that. Check the Pricing page for the current plans and for how purchase and trial work in the public beta.

FAQ

Do I need an account to use the image window?

No. Viewing, zoom, compare, capture and copying text work without an account. You sign in when you run a cloud AI Widget.

Does Glance Preview change my original file when I rotate or flip?

Not in the free view. Rotate and flip there affect the display, not the file. Saving those edits to the file is a Pro feature.

Is text recognition done in the cloud?

No. Glance Preview runs it on your Mac and does not upload the image.

Where do AI Widget results go?

They are saved as a new file in Downloads/Glance, so your original is not changed.
