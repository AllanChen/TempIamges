OpenAI's GPT Image 2.5 ships as two models, Flare and Sunburst, and the obvious question is which one to use for your own images. OpenAI's own advice is to test both on your workload with the same prompt and settings, then look closely at the results. This post covers what the two models are, how to run a fair test, and how to review the outputs side by side on a Mac with Glance Preview, including one-click fixes when a result is almost right.

Update (2026-11-05): OpenAI has released Images 2.6 (GPT Image 2.6 Flare and Sunburst). For new Flare vs Sunburst tests, prefer the 2.6 post; this 2.5 guide remains as a reference for the previous generation.

OpenAI suggests starting with Flare when speed matters and Sunburst when quality requirements are demanding. If Sunburst meets your bar, it recommends testing Flare with the same prompts and inputs and switching if Flare is good enough. In other words, the answer depends on your images, so you need a quick way to look at both outputs together.

How to run a fair Flare vs Sunburst test

  1. Keep everything the same except the model. Use the same prompt, the same reference images, the same size and the same quality setting. OpenAI notes that the same quality label does not guarantee the same image quality or speed across models, which is exactly why you compare the pictures, not the settings.
  2. Make a few outputs per model. One image each can mislead you; a handful per model gives a fairer picture of how each one behaves on your prompt.
  3. Name the files clearly, for example poster-flare-1.png and poster-sunburst-1.png, and save them to one folder on your Mac.
  4. Review matched pairs side by side, as described below, and note which model wins on the details you care about.

Compare the two outputs on your Mac

You can open both files in Preview and arrange two windows next to each other. That works, but it is fiddly to keep both images at the same zoom and position. Glance Preview is an image viewer for Apple silicon Macs that puts both images in one window:

  1. Open both images. Select the Flare and Sunburst files in Finder and open them together with Glance. If one is already open, drag the other into the window.
  2. Choose Compare in the toolbar to see the two images side by side. This suits framing, colour and overall look.
  3. Choose Slider and drag the divider across the same spot in both images. This suits small text, hands, edges and textures.
  4. Zoom into details before you decide. Comparing is a free viewing feature: no account, no credits, and your files are not changed.

The compare two images guide walks through both views in more detail.

What to look at closely

  • Text in the image: signs, labels and posters, where a single wrong letter ruins the image.
  • Faces and hands, and whether a subject stayed the same after an edit.
  • Fine materials and edges: fabric, glass, hair and thin lines.
  • Edits to a reference image: check that what you asked to keep really stayed the same.

Not quite right? Fix it from the preview

Sometimes the winning image is close but not finished. You can re-prompt the model, or you can run a one-click AI tool on the file you are already looking at. In Glance Preview, right-click the image and choose Widgets. The menu shows the credit cost before you run anything, and the result appears next to the original so you can check it with Compare or Slider again.

So which should you use?

  • Lots of drafts and quick iterations: start with Flare, as OpenAI suggests when speed matters.
  • Demanding quality or precise edits: start with Sunburst, then check whether Flare gets close enough on the same prompt.
  • Either way: decide by looking at matched outputs side by side, not by the model name.

FAQ

What is the difference between GPT Image 2.5 Flare and Sunburst?

Per OpenAI, Flare is the smaller model optimized for speed, with image quality comparable to GPT Image 2. Sunburst is the base model optimized for quality, with higher image quality than GPT Image 2. Both generate and edit images and support transparent backgrounds.

Do Flare and Sunburst cost the same?

OpenAI lists the same token rates for both models, matching GPT Image 2. Actual cost per image depends on how many tokens a request uses, so check OpenAI's pricing page for your settings.

How do I compare two AI images side by side on a Mac?

Open both files in Glance Preview and choose Compare for side by side or Slider to wipe between them at the same spot. You can also place two Preview windows next to each other.

Can Glance Preview generate images with GPT Image 2.5?

No. Glance Preview is a viewer with one-click cloud AI tools for an existing image, such as background removal, upscaling and expanding. It does not generate images from text.

Is comparing images in Glance Preview free?

Yes. Viewing and comparing images is free, needs no account and uses no credits. Credits are used by cloud AI Widgets.

Should I use GPT Image 2.5 or 2.6?

For new work, start with GPT Image 2.6 Flare vs Sunburst. OpenAI released Images 2.6 on 4 November 2026 with faster generation, GIF support and the same Flare/Sunburst split in the API. This page covers the 2.5 models if you still need them.
