Three image models are getting compared a lot this autumn: Black Forest Labs' open-weights FLUX 3 Image Klein, Alibaba's open-weights Qwen-Image-2.1, and Google's Nano Banana 2 (Gemini 3.1 Flash Image). All three can generate and edit images. This post sums up what each maker documents, shows how to set up a fair test, and walks through checking the outputs side by side on a Mac with Glance Preview, then fixing an almost-right result with a one-click AI Widget.

What the three models are

Facts below come from each maker's own pages, read on 2026-11-09 (Nano Banana 2 details from Google's pages as cited in our Nano Banana 2 vs Pro guide). Model names and details can change; treat the official pages as the source of truth.

  • FLUX 3 Image Klein (Black Forest Labs). Announced on 15 October 2026 in the BFL blog. Per the model card, it is a 5.6B-parameter open-weights model for image editing that also does text-to-image and multi-reference composition with up to 10 reference images. It can place elements with bounding boxes in the prompt. The text encoder (Qwen3-VL-4B-Instruct) is separate from the 5.6B figure. A base checkpoint for fine-tuning and a step-distilled checkpoint for generation are both released; the distilled one is also served on the BFL API as flux-3-image-klein.
  • Qwen-Image-2.1 (Qwen team, Alibaba). Released on 20 September 2026 per the GitHub repo; a faster Turbo version followed on 9 October 2026. The model card describes one model for text-to-image and editing with a 7B visual generation component, native transparent (RGBA) images, up to 10 reference images, and local edits marked with circles, painted annotations or masks.
  • Nano Banana 2 (Google). The nickname for Gemini 3.1 Flash Image (gemini-3.1-flash-image). A closed model you use through Google products and the Gemini API, with text rendering, subject consistency across references and output from 512px to 4K.

Running them on a Mac

  • FLUX 3 Image Klein. BFL lists the generator weights at 11.2 GB in BF16 and 5.6 GB in FP8, plus a separate 9B prompt upsampler (an 18.8 GB download) that the reference code runs by default. Its published speed and memory figures are for NVIDIA GPUs; BFL does not publish Apple silicon numbers. Without a suitable local setup, you can try it through the BFL API or a hosted demo.
  • Qwen-Image-2.1. The GitHub repo points to LightX2V-Mac-App, a native macOS app, for running Qwen-Image-2.1-Turbo locally on Apple silicon. The model card examples target CUDA GPUs.
  • Nano Banana 2. Runs on Google's servers; you download the results.

Whichever route you take, you end up with a folder of PNG or JPEG files on your Mac. That is where Glance Preview comes in. Glance Preview does not generate images from a prompt with any of these models.

How to run a fair test

  1. Use the same request for all three. Same prompt, same reference images, same aspect ratio. Pick a ratio all three support, such as 1:1, 3:2 or 16:9.
  2. Note the prompt expansion. BFL says FLUX 3 Image Klein expects full scene captions and that short prompts sent as typed give generic output, so its tools run the prompt upsampler by default. Write down whether it was on, so you know what you are comparing.
  3. Make a few images per model. One image each can mislead. Three or four show the pattern for text, faces and hands.
  4. Name the files clearly, for example poster-klein-1.png, poster-qwen-1.png and poster-nb2-1.png, and keep them in one folder.
  5. For edits, keep the original next to the results. The FLUX 3 Image Klein model card warns that edits can change content outside the requested region, so compare every edit against the source photo as well as against the other models.

Compare the outputs side by side on your Mac

You can open the files in Preview and arrange the windows, but matching zoom and position by hand is slow. Glance Preview puts two images in one window:

  1. Open two results. In Finder, select two files, for example the FLUX 3 Image Klein and the Qwen-Image-2.1 version, and open them together with Glance (Open With → Glance). If one is already open, drag the other into the window.
  2. Choose Compare in the toolbar for a side-by-side view. Good for framing, colour and overall look.
  3. Choose Slider and drag the divider across the same spot. Good for small text, hands, edges and whether an edit changed areas it should have left alone.
  4. Swap in the next file to check the third model against the current winner. Comparing is free: no account, no credits, and your files are not changed.

The compare two images guide explains both views in more detail.

What to look at closely

  • Text in the image: signs, labels and posters. All three makers highlight text rendering; BFL's card also says rendered text may be inaccurate or distorted.
  • Layout: if you used bounding boxes with FLUX 3 Image Klein, check that elements landed where you placed them. BFL notes boxes guide placement and are not a hard mask.
  • Faces and products across references: whether people and items still look like the reference images.
  • Edges and fine materials: hair, glass, fabric and thin lines.
  • Untouched areas in edits: slide across backgrounds and corners of edited photos.

So which should you try?

  • You want open weights you can fine-tune or self-host: FLUX 3 Image Klein and Qwen-Image-2.1 both qualify. Read each license before you start; they differ.
  • You need transparent PNGs straight from the model: Qwen-Image-2.1 documents native RGBA output.
  • You want to place elements precisely: FLUX 3 Image Klein documents bounding-box layout.
  • You want nothing to install: Nano Banana 2 runs in Google's apps and API.
  • In every case: decide by looking at matched outputs side by side, not by the model name.

Glance Preview runs on Apple silicon Macs with macOS 12.3 or later. The install page has the current download and first-launch steps.

FAQ

What is FLUX 3 Image Klein?

FLUX 3 Image Klein is a 5.6B-parameter open-weights image model from Black Forest Labs, released on 15 October 2026. One model does image editing, text-to-image and multi-reference composition with up to 10 reference images, and it can place elements with bounding boxes. It is available as weights on Hugging Face and through the BFL API.

What is the difference between FLUX 3 Image Klein and Qwen-Image-2.1?

Both are open-weights models that generate and edit images with up to 10 references. By each maker's figures, FLUX 3 Image Klein's image generator is 5.6B parameters and Qwen-Image-2.1's is 7B. FLUX 3 Image Klein adds bounding-box layout and a prompt upsampler; Qwen-Image-2.1 adds native transparent (RGBA) output and marks local edits with circles, annotations or masks. Their licenses differ.

Can I use FLUX 3 Image Klein commercially?

It is released under the FLUX Kommunity License. Per BFL's model card, that license allows non-commercial use and has a commercial-output exception for qualifying users with less than US$5M in gross annualized revenue, subject to its terms. Read the full license or ask BFL about commercial licensing before you rely on it.

Does Glance Preview run FLUX 3 Image Klein?

No. Glance Preview is an image viewer with one-click cloud AI Widgets. It has no text-to-image Widget, and no Widget uses FLUX 3 Image Klein. Per its AI model disclosure, Upscale uses Nano Banana 2, Outfit Swap uses Qwen-Image-2.1, and Expand Image uses FLUX.2.

How do I compare AI images side by side on a Mac?

Open two files in Glance Preview and choose Compare for side by side, or Slider to wipe between them at the same spot. Without extra apps, you can place two Preview windows next to each other.

Is comparing images in Glance Preview free?

Yes. Viewing and comparing images is free, needs no account and uses no credits. Credits are used by cloud AI Widgets.
