Widgets add cloud tools to Glance Preview, including AI edits: background removal, upscaling, expanding the canvas and more. You pick the ones you want from the Widget Market, and they appear in the right-click menu of the image window. The Widgets listed here run in the cloud and use credits, and its cost is shown before you run it. This is part 2 of the Glance tutorial series; if you have not installed Glance yet, start with Getting started with Glance on Mac.

What you need

  • Glance Preview installed on an Apple silicon Mac (see the install page).
  • An internet connection: the Market loads its list of Widgets from Glance's server, and Widgets run in the cloud.
  • A Glance account for running Widgets. You sign in with Google or an email code the initial time you run a cloud Widget; viewing and comparing need no account.

Step 1: Open the Widget Market

Open any image in the full Glance window, then use one of these:

  • Click the Widget button in the window's toolbar.
  • Right-click the image and open the Widget Market from the menu. If you have not added any Widget yet, the Market entry is what the menu offers in place of a Widget list.

Step 2: Pick a Widget and add it

  1. Browse or search the list. Each Widget shows what it does and its credit cost per run.
  2. Open a Widget to read its details, including how it handles the file you send it, then install it.
  3. The Widget now appears under Widgets in the right-click menu of every image (or video) it accepts.

Step 3: Run a Widget from the right-click menu

  1. In the full window, right-click the image and choose Widgets. Each Widget's credit cost is shown before you run it.
  2. Choose a Widget. On your initial cloud run, Glance asks you to sign in. New accounts start with 100 credits.
  3. Some Widgets need an input from you: Remove Objects takes a short English description of what to remove, Redraw & Reframe takes an aspect ratio, and Outfit Swap takes a second image with the outfit.
  4. The task runs in the background, so you can keep browsing other images. The Task Center lists queued, running and finished tasks, and you can cancel a task that is still queued.
  5. For image-editing Widgets, the finished image appears alongside the original. Image to Prompt returns text; Free Image Host returns a shareable link. Keep the original when saving your result.

For image results, check edges, text and areas you wanted to preserve with Compare or Slider. AI results can change details you did not intend to edit.

What 100 starting credits cover

The 100 credits a new account starts with are enough for, for example:

  • 5 background removals (5 × 20), or
  • 3 upscales or expands (3 × 30 = 90), or
  • 2 background removals and 2 upscales (40 + 60).

A single 10-second video run uses all 100.

How credits work

  • Credits are used by cloud Widgets. Viewing, comparing and the local tools never use credits.
  • Check before running. Read the displayed credit cost and the Widget's input requirements before submitting a task.
  • If a task fails. Check its status and your credit balance before retrying. Contact support if the result or billing remains unclear.
  • Your balance is per account and shared across your Macs. Credits never expire.
  • More credits. Credit packs are one-time payments that never renew; current packs and prices are on the Pricing page.
  • Pro and Widget credits are separate. Pro is a separate one-time purchase for the local toolbox and comes with 100 bonus credits; Widgets keep using credits.

Good to know

  • Your file goes to the cloud. Running a Widget uploads the image or video to Glance for processing. Each Widget's details in the Market say how it handles your file.
  • Widgets can change. New Widgets can be added and prices can change; the Market and the Widgets page show the current list.

FAQ

Where is the Widget Market in Glance Preview?

In the full image window: click the Widget button in the toolbar, or right-click the image and open the Widget Market from the menu.

Do I need an account to use Widgets?

Yes, to run them. Glance Preview asks you to sign in with Google or an email code the initial time you run a cloud Widget. Viewing and comparing images need no account.

Is Free Image Host free to run?

Despite its name, the current public catalog lists Free Image Host at 29 credits per file. Check the displayed price before uploading.

How many credits does a Glance Preview Widget cost?

Image Widgets cost 20 to 30 credits per image: Background Remover Pro and Image to Prompt cost 20, Free Image Host 29, and Upscale, Expand Image, Redraw & Reframe, Remove Objects, Watermark Remover and Outfit Swap 30. Video Watermark Remover costs 100 credits per 10 seconds of video.

How many free credits do I get?

New accounts start with 100 credits, enough for five background removals or three upscales.

How do I get more credits?

Credit packs are one-time payments that never renew. Current packs and prices are listed on the Pricing page.

What happens if a Widget task fails?

Check the task status and credit balance before retrying. If the result or charge remains unresolved, contact support with the task details.

Do credits expire?

No. Credits never expire and are shared across your Macs.
