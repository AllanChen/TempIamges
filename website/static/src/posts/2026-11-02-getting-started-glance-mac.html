Glance Preview is an image viewer for Apple silicon Macs built around one loop: look at an image quickly, and if it is not right, fix it with a one-click AI tool and compare the result with the original. This guide takes you from download to that loop in about ten minutes: install the beta, open images, turn on Peek, and run an AI Widget on one image.

What you need

  • A Mac with Apple silicon (M-series).
  • macOS 12.3 or later.
  • No account and no system permissions to start viewing. An account is needed just for the cloud AI Widgets.

Step 1: Download and install the beta

  1. Go to the install page, download the Glance DMG and double-click it.
  2. Drag Glance into the Applications folder.
  3. Double-click Glance in Applications.

If macOS blocks the launch

The beta is not notarized by Apple yet, so macOS blocks it the initial time you open it. This is expected; you allow it once.

macOS 15 (Sequoia) and later:

  1. Double-click Glance. When you see "cannot be opened", click Done.
  2. Open System Settings → Privacy & Security and scroll down to Security.
  3. Next to "Glance was blocked", click Open Anyway and confirm with your password.

macOS 14 and earlier: right-click Glance in Applications, choose Open, then click Open again in the dialog.

After that, Glance opens normally with a double-click. It runs as a regular app with a Dock icon and a menu bar icon, and the 14-day full trial starts at launch.

Step 2: Open an image in Glance

  • From Finder: right-click an image or video and choose Open With → Glance.
  • As your default viewer: set Glance as your default viewer from its menu bar icon, and double-clicking images opens them in Glance.
  • Two images at once: select two images and open them together to go straight to a comparison.

The image opens in the full Glance window. This is where the AI tools and the Compare and Slider views live.

Step 3: Turn on Peek for previews from selected text

Peek previews an image link or file path you have selected in any app, without switching apps. It is optional and off by default.

  1. Open Glance's Preferences and turn on Peek.
  2. Grant the Accessibility and Input Monitoring permissions Glance asks for. They are used to detect the hotkey and read the text you selected.
  3. In any app, select text that contains an image link or file path and press Option + Space.

The selected text is not sent to Glance's servers. For a web link, Glance loads the preview directly from that website.

The AI tools are in the full window, so open the image there when you want to fix it.

Step 4: Fix an image with an AI Widget

  1. In the full window, right-click the image and choose Widgets. Each Widget shows its credit cost before you run it. If the tool isn't in your Widgets menu yet, add it from the Widget Market (the Widget button in the toolbar).
  2. Pick a one-click Widget such as Background Remover Pro.
  3. The initial cloud run asks you to sign in with Google or an email code. New accounts start with 100 credits.
  4. The task runs in the cloud in the background, so you can keep browsing other images.
  5. When it finishes, the result is saved as a new file and placed next to the original; your original is not changed.

Step 5: Compare the result with the original

Click Compare to see the original and the result side by side, or Slider to drag a divider across the pair. Check edges, faces and text at full size before you keep a result, especially with generative tools such as Upscale, which can add detail that was not in your picture.

Good to know

  • Cloud AI. Widgets upload the image to Glance for processing and need an internet connection. Viewing and comparing stay on your Mac.
  • Credits. More credit packs can be bought in the app. If a task fails on Glance's side, the credits are returned, as described on the Pricing page.
  • Help. Send a direct message on X to {{SUPPORT_X}}; a screenshot or the log file ~/Library/Application Support/Glance/app.log helps.
  • Uninstall. Quit Glance and drag it from Applications to the Trash. To remove local settings and logs, delete ~/Library/Application Support/Glance.

FAQ

Which Macs does Glance Preview run on?

Apple silicon (M-series) Macs with macOS 12.3 or later.

Why does macOS say Glance cannot be opened?

The beta is not notarized by Apple yet. Allow it once in System Settings → Privacy & Security (macOS 15 and later), or right-click the app and choose Open (macOS 14 and earlier).

Do I need an account to view images?

No. An account is needed just for the cloud AI Widgets.

What is the Peek hotkey?

Option + Space by default. Turn Peek on in Preferences; it is off by default.

Does Peek send my selected text to Glance?

No. For a web link, Glance loads the preview directly from that website.
