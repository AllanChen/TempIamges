Glance ガイド · 画像の文字

Mac で画像から文字をコピーする1 行だけ選ぶことも、全文を見ることも。

macOS のプレビューでも「テキスト認識表示（Live Text）」で文字をコピーできます。Glance では、開いた画像の文字を直接選択したり、認識結果を全文で表示したりできます。文字認識は Mac 上で行われ、Pro もクレジットも不要です。

Glance をダウンロード手順を見る

Glance で選択してコピーする

  1. 画像を開く。文字を含む画像を Glance の Image Inspection ウィンドウで表示し、ローカルの認識が終わるのを待ちます。
  2. 必要な部分を選ぶ。画像の文字をドラッグして選択し、⌘C でコピーして、書類やほかのアプリに貼り付けます。
  3. 全文が必要なら Tools → Recognize Text を選びます。結果パネルに現在の画像から認識した文字が表示され、確認してコピーできます。

標準機能で済ませたい場合は、Apple のプレビューのテキスト認識表示ガイドで、Glance をインストールせずに文字を選択・コピーする方法を確認できます。

うまく認識されないとき

元画像を確認する

ぼやけ、小さすぎる文字、傾き、映り込み、低いコントラストは結果に影響します。小さなスクリーンショットではなく、鮮明な元画像で試してください。

全文の結果を見る

文字がまだ選択できない場合は、Tools → Recognize Text で結果を確認します。認識に失敗したときの再試行にもなります。

日本語について：Glance は現在、macOS の Vision が対応する範囲で簡体字中国語と英語を優先して認識します。日本語の文字は認識されないか、精度が下がる場合があります。日本語の画像は、macOS 標準のテキスト認識表示も併用してください。重要な文字は必ず画像と照らし合わせて確認してください。

ローカル認識とクラウドツール

画像の文字認識は Mac 上で行われ、OCR のために画像がアップロードされることはありません。メディアがアップロードされるのは、クラウド AI ウィジェットを実行したときだけです。詳しくはプライバシーポリシー（英語）をご覧ください。
