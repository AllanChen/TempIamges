OpenAI は 2026 年 11 月 4 日に Images 2.6 を ChatGPT・Codex・API 向けに公開しました。API では GPT Image 2.6 Flare と GPT Image 2.6 Sunburst の 2 モデルです。Flare はすばやい試行向け、Sunburst は細部と編集の一貫性向けです。この記事では OpenAI の公式説明を整理し、公平な比較の手順と、Glance Preview で Mac 上のダウンロードを並べて確認し、惜しい画像をワンクリックで直す流れを紹介します。

※ Glance Preview のアプリ表示は英語・簡体字中国語・日本語に対応しています。

Images 2.6 で増えたこと

OpenAI の Introducing Images 2.6（英語）と 画像プロンプトガイド（英語、2026-11-05 時点）によると:

  • 生成が速い。OpenAI は従来より約 50% 速いとしています。quality を low にすると、Flare は最短で約 6 秒程度で画像を返す場合があります。
  • GIF アニメ。ChatGPT Images 2.6 と Image API は、プロンプトからループ GIF を作れます（API の generations では output_format=gif）。
  • 透過背景と SVG。両モデルとも透過背景に対応。API の生成ではロゴなどの SVG 出力も可能です。
  • 編集の制御。ChatGPT にあったマークアップ指定編集が API にも入り、complexity（low / medium / high）で描画前の計画量を調整できます。
  • 提供範囲。Images 2.6 は ChatGPT と Codex の全サブスクリプション階層（デスクトップ・モバイル・Web）で利用可能。Flare / Sunburst は API のモデル ID です。

Glance Preview は GPT Image 2.6 を実行せず、テキストから画像を生成することもありません。流れは「外で生成・編集 → ダウンロード → Mac でプレビュー／必要なら修正」です。

OpenAI の勧めは 2.5 世代と同様です。速さを優先するなら Flare から、品質や編集精度が厳しいなら Sunburst から。Sunburst で足りたら同じプロンプトで Flare も試し、十分なら Flare に切り替えます。ChatGPT では製品名が Images 2.6、Flare / Sunburst は API での A/B 用のモデル名です。

前世代を使う場合は GPT Image 2.5 Flare と Sunburst の記事も参照してください。新しい比較では 2.6 を優先するのがよいです。

Flare と Sunburst を公平に比べる手順

  1. モデル以外はすべて同じにする。プロンプト、参照画像、サイズ、品質、complexity をそろえます。同じ品質ラベルでもモデルが違えば見た目や速度は同じとは限りません。
  2. 各モデルで数枚ずつ生成する（API を使わない場合は ChatGPT の Images 2.6 で複数回）。1 枚ずつでは偶然に左右されます。
  3. ファイル名を分かりやすくする。例: poster-flare-1.png と poster-sunburst-1.png。透過 PNG/WebP はアルファを保ったまま保存。GIF は返ってきた .gif をそのまま保存。
  4. 対応するペアを並べて確認し、気になる部分でどちらが良いかをメモします。

Mac でダウンロードをプレビュー・比較する

macOS の「プレビュー」でウインドウを 2 つ並べることもできますが、拡大率や位置をそろえるのは手間です。Glance Preview は Apple シリコン搭載 Mac 向けの画像ビューアで、2 枚を 1 つのウインドウで比べられます。

  1. 2 枚を開く。Finder で Flare と Sunburst の画像を選び、「このアプリケーションで開く」から Glance でまとめて開きます。すでに 1 枚開いているなら、もう 1 枚をウインドウにドラッグします。別アプリでパスや画像リンクを選んで Peek（任意・初期オフ）でプレビューし、Compare や Widgets が必要ならフルウインドウを開く方法もあります。
  2. ツールバーの Compare で左右に並べます。構図・色・全体印象向けです。
  3. Slider で境界線を同じ位置にドラッグします。小さな文字、手、輪郭、質感向けです。
  4. 透過 PNG。切り抜きを忙しい背景の上で確認します。まだ背景が残る場合は background=transparent で再生成するか、後述の Background Remover Pro を使います。
  5. GIF。ダウンロードした GIF を Glance Preview で開き、Mac 上のファイルとしてのループ感を見ます。静止画同士の厳密な A/B なら、対応フレームを書き出すか PNG/WebP を使い、Compare / Slider で比べます。
  6. 拡大して細部を見る。比較は無料の表示機能で、アカウントもクレジットも不要、元ファイルも変更しません。

詳しい操作は 2 枚の画像を比較するガイドをご覧ください。初回起動でブロックされた場合の手順は、Apple のMac でアプリを安全に開くも参考になります。

特によく見るべきポイント

  • 画像内の文字：看板、ラベル、ポスター。日本語の文字は特に念入りに。
  • 顔・手・ブランドマーク、編集後も同じ被写体か。
  • 細かい素材と輪郭：布、ガラス、髪、細い線。
  • 参照画像の編集：残したい部分が本当に変わっていないか（マークアップで変更箇所を指定できる）。
  • GIF のループ：最初のフレームに自然に戻るか、ブランド要素がフレーム間でぶれないか。

惜しい画像はプレビューからそのまま直す

選んだ画像があと一歩のこともあります。Images 2.6 でプロンプトを変えて再生成する方法のほか、表示中のファイルにワンクリックの AI ツールをかける方法もあります。Glance Preview では画像を右クリックして Widgets を選びます（一覧にない場合は先に Widget Market から追加）。実行前にメニューにクレジットが表示され、結果は元画像の隣に出るので、もう一度 Compare や Slider で確認できます。

注意点も 2 つあります。GPT Image 2.6 はもともと透過・大きいサイズ・SVG・GIF に対応しているので、プロンプトが手元なら設定を変えて再生成した方が簡単な場合もあります。Widgets は別のクラウド AI で動き、AI モデルの開示ページに一覧があります（例: Upscale は Google Gemini 3.1 Flash Image / Nano Banana 2、Expand Image は FLUX.2）。Glance Preview は GPT Image 2.6 を呼びません。クラウド Widget は画像をアップロードし、サインインが必要です。新規アカウントには 100 クレジットが付き、アプリ内でクレジットを追加購入できます。Glance 側の失敗はクレジットが返却されます（料金ページ）。手順は背景の削除、高画質化、画像の拡張を参照してください。

結局どちらを使えばいい？

  • 下書きを大量に・すばやく試す：OpenAI が速度重視で勧めるとおり Flare（または ChatGPT の速い Images 2.6 実行）から。
  • 品質要件が厳しい・精密な編集・ブランド一貫性：Sunburst から始め、同じプロンプトで Flare が十分近いかも確認。
  • モーションやロゴ系：OpenAI が文書化している範囲で GIF や SVG を試し、出荷前に Mac 上のファイルを確認。
  • どちらの場合も：モデル名ではなく、対応する出力を並べて見て決めましょう。

よくある質問

GPT Image 2.6 の Flare と Sunburst の違いは？

OpenAI によると、Flare は速度重視の小さいモデル（low 品質で約 6 秒程度の例あり）です。Sunburst は細部と編集の一貫性向けのベースモデルです。どちらも生成・編集・透過に対応し、API の generations では GIF と SVG も使えます。

Images 2.6 は ChatGPT で使えますか？

はい。OpenAI は ChatGPT と Codex の全サブスクリプション階層（デスクトップ・モバイル・Web）で Images 2.6 が利用可能だとしています。Flare / Sunburst は API のモデル名です。

GPT Image 2.6 で GIF や透過 PNG は作れますか？

OpenAI の文書によれば可能です。ChatGPT Images 2.6 は GIF を作成でき、API では generations の output_format=gif と PNG/WebP（および SVG）の background=transparent に対応します。edit エンドポイントは GIF/SVG を出力しません。

Mac で 2 枚の AI 画像を並べて比較するには？

Glance Preview で 2 枚を開き、左右なら Compare、同じ位置で切り替えるなら Slider を選びます。macOS の「プレビュー」を 2 ウインドウ並べる方法もあります。

Glance Preview で GPT Image 2.6 の画像を生成できますか？

いいえ。Glance Preview はビューアで、手元の画像に背景削除・高画質化・拡張などのワンクリックのクラウド AI をかけられます。テキストから画像を生成せず、GPT Image 2.6 も呼び出しません。

Glance Preview での画像比較は無料ですか？

はい。表示と比較は無料で、アカウントもクレジットも不要です。クレジットはクラウド AI Widget で使います。
