Google の Gemini 画像モデルには Nano Banana という愛称があります。Nano Banana 2 は Gemini 3.1 Flash Image で、Flash の速さで生成・編集するモデルです。Nano Banana Pro は Gemini 3 Pro Image で、より複雑で精度の高い作業向けに位置づけられています。この記事では Google の公式説明を整理し、Glance Preview で Mac 上のダウンロードを公平に比べ、惜しい画像をワンクリックで直す流れを紹介します。

※ Glance Preview のアプリ表示は英語と簡体字中国語のみです。

Nano Banana 2 と Pro とは

Google の Nano Banana 2 発表（2026 年 2 月 26 日、英語）と Gemini API の画像生成ドキュメント（英語、2026-11-06 時点）によると:

  • Nano Banana 2 = Gemini 3.1 Flash Image（gemini-3.1-flash-image）。Web 検索に基づく世界知識、テキスト描画・翻訳、被写体の一貫性、512px〜4K の制作向け解像度など、Pro 系の機能を Flash の速さで使うモデルです。
  • Nano Banana Pro = Gemini 3 Pro Image（gemini-3-pro-image）。複雑なビジュアル作業、高度なローカライズ、ブランド一貫性、精密なコントロール向けのプレミアムモデルです。
  • 利用場所。Gemini アプリ、Search（AI モード / Lens）、AI Studio + Gemini API、Vertex AI、Flow、Google Ads などに掲載されています。製品・アカウント・地域で差があるため、Google の各ページで確認してください。
  • 出所表示。生成画像には SynthID 透かしと C2PA Content Credentials が付くと Google は説明しています。

Google Cloud の Nano Banana プロンプトガイド（英語、2026-11-06 時点）では、Nano Banana 2 の入力コンテキストが Pro より大きく、512px（0.5K）を追加し、共有のアスペクト比（1:1〜21:9）に加えて 1:4・4:1・1:8・8:1 などの極端な比率に対応するとあります。どちらも複数の参照画像を 1 つのプロンプトに混ぜられます。

Gemini API のドキュメントには Nano Banana 2.1 や Nano Banana 2 Lite などの関連モデルも載っています。本ページは検索が多い 2 と Pro の比較に絞ります。モデル名と ID は変わることがあるので、Google の公式ドキュメントを正としてください。

Glance Preview はテキストプロンプトから Nano Banana 2 / Pro で画像を生成しません。流れは「Gemini・AI Studio・API など外で生成・編集 → ダウンロード → Mac でプレビュー／必要なら修正」です。例外として、Glance の Upscale ウィジェットの基盤モデルは AI モデル開示どおり Google Gemini 3.1 Flash Image（Nano Banana 2）です。これは手元の画像を高画質化する image-to-image であり、テキストからの新規生成ではありません。

公平に比べる手順

  1. モデル以外はすべて同じにする。プロンプト、参照画像、アスペクト比、解像度（両対応の範囲）をそろえます。Pro にない極端な比率や 512px 下書きが必要な場合は、品質差ではなく対応差として記録します。
  2. モデルごとに数枚出す。1 枚だけだと偏ります。文字・顔・ブランド要素の傾向を見るには複数枚が安心です。
  3. ファイル名をはっきり付ける。例: poster-nb2-1.png と poster-pro-1.png。同じフォルダに保存します。
  4. 対応するペアを並べて確認し、気になる細部でどちらが勝つかメモします。

Mac でダウンロードをプレビューして比較する

プレビューで 2 つのウィンドウを並べてもできますが、ズームやパンをそろえるのは手間です。Glance Preview なら 1 つのウィンドウで両方を扱えます。

  1. 両方の画像を開く。Finder で Nano Banana 2 と Pro のファイルを選び、「このアプリケーションで開く」→ Glance。すでに一方が開いているなら、もう一方をウィンドウへドラッグ。別アプリでパスや画像リンクを選んで Peek（任意・既定オフ）で覗き、Compare や Widgets が必要ならフルウィンドウを開きます。
  2. ツールバーの Compare で左右並び。構図・色・全体の印象向きです。
  3. Slider で仕切りを同じ位置にドラッグ。小さな文字・手・輪郭・質感向きです。
  4. 細部を拡大してから決める。表示と比較は無料で、アカウントもクレジットも不要、元ファイルは変わりません。

詳しい操作は Mac で 2 枚の画像を比較する を参照してください。

とくに見るポイント

  • 画像内の文字:看板、ラベル、ポスター、ローカライズした文言。Google はこれらのモデルでテキスト描画・翻訳を強調しています。
  • 顔・キャラクター・ブランドマークと、参照画像を使ったときの一貫性。
  • 素材と輪郭:布、ガラス、髪、細い線。
  • レイアウトと個数:指定した数・位置どおりか。
  • 極端な比率:Nano Banana 2 で超ワイド／超縦長にしたときは、端の文字や輪郭も確認します。

惜しいときは、表示中の画像から直す

勝ち画像でも仕上げが残ることがあります。Gemini や API で再生成するか、いま見ているファイルにワンクリックの AI ツールをかけられます。Glance Preview で画像を右クリックし Widgets を選びます（一覧にない場合は先に Widget Market から追加）。メニューにクレジット数が表示され、結果は元画像の隣に出るので、もう一度 Compare や Slider で確認できます。

正直な注記です。Nano Banana 系は大きな解像度や多様な比率に対応できるため、プロンプトが残っているなら設定を変えて再生成した方が簡単なこともあります。ウィジェットは別のクラウドツールで、AI モデル開示と AI ウィジェットに載っています（Upscale は Gemini 3.1 Flash Image / Nano Banana 2、Expand Image は FLUX.2、Redraw & Reframe は Krea 2）。Glance Preview は Nano Banana Pro を呼び出しません。クラウドウィジェットは画像をアップロードし、サインインが必要です。新規アカウントは 100 クレジットから。Glance 側の失敗ではクレジットが戻ります（料金ページ）。手順ガイド: 背景削除、高画質化、画像の拡張。

どちらを使うか

  • 下書きをたくさん・すばやく回したい:Google が Flash 速度と日常品質を強調する Nano Banana 2 から。
  • 精度・ブランド一貫性・複雑なローカライズが厳しい:同じプロンプトで Pro を試し、2 で足りるかも確認。
  • 極端なアスペクト比や 512px の下書き:Cloud ガイド上、2 に Pro にない選択肢があります。
  • どちらでも:モデル名ではなく、Mac 上で並べた結果で決める。

Glance Preview 自体は Apple silicon の Mac、macOS 12.3 以降向けです。最新のダウンロードと初回起動は インストールページを参照してください。

よくある質問

Nano Banana 2 と Nano Banana Pro の違いは？

Google によると、Nano Banana 2 は Gemini 3.1 Flash Image で、Flash 速度に加え世界知識・テキスト描画・512px〜4K などの機能を持つモデルです。Nano Banana Pro は Gemini 3 Pro Image で、複雑で精密な作業向けのプレミアムモデルです。どちらも生成と編集に対応し、解像度やアスペクト比の上限はドキュメント上異なります。

Nano Banana 2 は Gemini 3.1 Flash Image と同じですか？

はい。Google は Nano Banana 2 を Gemini 3.1 Flash Image の愛称として使っています。Nano Banana Pro は Gemini 3 Pro Image の愛称です。

Glance Preview で Nano Banana 2 / Pro の画像生成はできますか？

テキストから画像を作るウィジェットはありません。Glance Preview は既存画像向けのワンクリッククラウド AI ツール付きビューアです。Upscale は手元のファイルを高解像度化する際に Gemini 3.1 Flash Image（Nano Banana 2）を使います。Nano Banana Pro は呼び出さず、プロンプトだけで新規生成もしません。

Mac で AI 画像を 2 枚並べて比べるには？

Glance Preview で両方を開き、Compare で左右並び、Slider で同じ位置をすり合わせます。プレビューのウィンドウを 2 つ並べる方法もあります。

Glance Preview での比較は無料ですか？

はい。表示と比較は無料で、アカウントもクレジットも不要です。クレジットはクラウドの AI ウィジェットで使います。

Nano Banana 2.1 や 2 Lite は？

Gemini API のドキュメントには関連モデルとして載っています。本ページの 2 vs Pro 比較の対象外なので、最新の ID は API の画像生成ページで確認してください。
