この秋よく比較されている画像モデルが 3 つあります。Black Forest Labs のオープンウェイト「FLUX 3 Image Klein」、Alibaba のオープンウェイト「Qwen-Image-2.1」、Google の「Nano Banana 2」（Gemini 3.1 Flash Image）です。どれも画像の生成と編集ができます。この記事では各社の公式情報をまとめ、公平な比べ方と、Mac の Glance Preview で結果を並べて確認し、惜しい画像をワンクリックの AI ウィジェットで直す流れを紹介します。

※ Glance Preview のアプリ表示は英語と簡体字中国語のみです。

3 つのモデルの概要

以下は各社の公式ページ（英語、2026-11-09 時点）に基づきます。Nano Banana 2 は Nano Banana 2 と Pro の比較記事で引用した Google の資料によります。モデル名や仕様は変わることがあるため、公式ページを正としてください。

  • FLUX 3 Image Klein（Black Forest Labs）。2026 年 10 月 15 日に BFL のブログで発表。モデルカードによると、画像編集向けに設計された 5.6B パラメータのオープンウェイトモデルで、テキストからの生成や最大 10 枚の参照画像を使った合成も 1 つのモデルで行えます。プロンプト内のバウンディングボックスで配置を指定できます。テキストエンコーダー（Qwen3-VL-4B-Instruct）は 5.6B に含まれません。ファインチューニング用の Base 版と、生成用の蒸留版が公開され、蒸留版は BFL API でも flux-3-image-klein として提供されています。
  • Qwen-Image-2.1（Alibaba の Qwen チーム）。GitHub によると 2026 年 9 月 20 日公開、高速版の Turbo は 10 月 9 日公開。モデルカードでは、画像生成部分が 7B の生成・編集統合モデルで、透過（RGBA）画像をそのまま出力でき、参照画像は最大 10 枚、丸囲み・書き込み・マスクで部分編集を指定できると説明されています。
  • Nano Banana 2（Google）。Gemini 3.1 Flash Image（gemini-3.1-flash-image）の愛称です。重みは非公開で、Google の各サービスと Gemini API から使います。文字描画、参照画像をまたいだ被写体の一貫性、512px〜4K の出力が特長です。

開発元が出している速度や品質のランキングは自社評価なので、ここでは事実として載せません。自分の用途に合うかは、同じ条件の出力を見て判断するのが確実です。

Mac で動かす場合

  • FLUX 3 Image Klein：BFL によると生成部の重みは BF16 で 11.2 GB、FP8 で 5.6 GB。さらに参照コードは既定で 9B のプロンプトアップサンプラー（ダウンロード 18.8 GB）を使います。公開されている速度・メモリの数値は NVIDIA GPU のもので、Apple シリコンの数値は出ていません。ローカル環境がなければ、BFL API や公開デモで試せます。
  • Qwen-Image-2.1：GitHub では、Apple シリコンで Qwen-Image-2.1-Turbo をローカル実行できる macOS アプリ「LightX2V-Mac-App」が紹介されています。モデルカードのサンプルコードは CUDA GPU 向けです。
  • Nano Banana 2：Google のサーバーで動き、結果をダウンロードします。

どの方法でも、最後は Mac に PNG や JPEG のフォルダができます。Glance Preview が役立つのはここからです。Glance Preview 自体は、これらのモデルでプロンプトから画像を生成しません。

公平に比べる手順

  1. 3 つとも同じ依頼にする。プロンプト、参照画像、アスペクト比をそろえます。1:1、3:2、16:9 など 3 つとも対応する比率を選びます。
  2. プロンプト展開の有無をメモする。BFL は、FLUX 3 Image Klein は詳細なシーン説明を前提にしており、短いプロンプトをそのまま送ると平凡な出力になると説明しています。そのため公式ツールは既定でアップサンプラーを使います。オンかオフかを記録しておくと、何を比べたのかが明確になります。
  3. モデルごとに数枚出す。1 枚ずつでは偏ります。3〜4 枚あれば、文字・顔・手の傾向がわかります。
  4. ファイル名で区別する。例：poster-klein-1.png、poster-qwen-1.png、poster-nb2-1.png。1 つのフォルダにまとめます。
  5. 編集なら元画像も横に置く。FLUX 3 Image Klein のモデルカードには、指定範囲の外まで変わることがあると書かれています。他モデルとの比較だけでなく、元写真とも必ず見比べてください。

Mac で生成結果を並べて比べる

プレビュー.app で 2 つのウインドウを並べることもできますが、拡大率や位置を手で合わせるのは手間です。Glance Preview なら 2 枚を 1 つのウインドウで比べられます。

  1. 2 枚を開く。Finder で FLUX 3 Image Klein 版と Qwen-Image-2.1 版など 2 つのファイルを選び、「このアプリケーションで開く」→ Glance で一緒に開きます。1 枚目がすでに開いていれば、もう 1 枚をウインドウにドラッグします。
  2. Compare を選ぶ。ツールバーの Compare で左右に並べます。構図・色・全体の印象を見るのに向いています。
  3. Slider を選ぶ。境界線を同じ場所でドラッグします。小さな文字、手、輪郭、編集で変わってはいけない部分の確認に向いています。
  4. 3 枚目と入れ替える。暫定の勝者と 3 つ目のモデルを比べます。比較は無料で、アカウントもクレジットも不要、ファイルも変更されません。

2 つの表示方法の詳細は Mac で 2 枚の画像を比較するをご覧ください。

見るべきポイント

  • 画像内の文字：看板・ラベル・ポスター。3 社とも文字描画を強調していますが、BFL のモデルカードは文字が崩れることがあるとも書いています。日本語の文字は特に念入りに確認してください。
  • レイアウト：FLUX 3 Image Klein でボックスを使った場合、要素が指定位置に来ているか。BFL によるとボックスは配置の目安で、厳密なマスクではありません。
  • 参照画像との一致：人物や商品が参照画像のままに見えるか。
  • 輪郭と質感：髪、ガラス、布、細い線。
  • 編集で触れていない部分：背景や四隅を Slider でなぞります。

惜しい画像はプレビューからそのまま直す

プロンプトを変えて作り直す方法もありますが、いま見ているファイルにワンクリックの AI ツールを使う方法もあります。Glance Preview で画像を右クリックして Widgets を選びます（一覧にない場合は先に Widget Market から追加）。実行前にクレジット数が表示され、結果は元画像の隣に開くので、そのまま Compare や Slider で確認できます。

どれを試すべき？

  • ファインチューニングや自前運用をしたい：FLUX 3 Image Klein と Qwen-Image-2.1 はどちらもオープンウェイトです。ライセンスの条件が違うので先に確認してください。
  • 透過 PNG をモデルから直接ほしい：Qwen-Image-2.1 が RGBA 出力に対応しています。
  • 要素の位置を細かく決めたい：FLUX 3 Image Klein のバウンディングボックス指定が使えます。
  • 何もインストールしたくない：Nano Banana 2 は Google のアプリと API で使えます。
  • どの場合も：モデル名ではなく、同じ条件の出力を並べて決めましょう。

Glance Preview は macOS 12.3 以降の Apple シリコン Mac で動きます。最新版のダウンロードと初回起動の手順はインストールページにあります。

よくある質問

FLUX 3 Image Klein とは？

Black Forest Labs が 2026 年 10 月 15 日に公開した、5.6B パラメータのオープンウェイト画像モデルです。画像編集、テキストからの生成、最大 10 枚の参照画像を使った合成を 1 つのモデルで行い、バウンディングボックスで配置も指定できます。重みは Hugging Face で公開され、BFL API からも使えます。

FLUX 3 Image Klein と Qwen-Image-2.1 の違いは？

どちらもオープンウェイトで、最大 10 枚の参照画像を使って生成・編集できます。各社の発表では画像生成部が FLUX 3 Image Klein は 5.6B、Qwen-Image-2.1 は 7B です。FLUX 3 Image Klein はボックスによるレイアウト指定とプロンプトアップサンプラー、Qwen-Image-2.1 は透過（RGBA）出力と丸囲み・書き込み・マスクによる部分編集が特長です。ライセンスも異なります。

FLUX 3 Image Klein は商用利用できますか？

FLUX Kommunity License で公開されています。BFL のモデルカードによると、非商用利用が認められ、年間総収入 500 万米ドル未満などの条件を満たす利用者には出力の商用利用の例外があります。利用前にライセンス全文を確認するか、BFL に商用ライセンスを問い合わせてください。

Glance Preview で FLUX 3 Image Klein は使えますか？

使えません。Glance Preview はワンクリックのクラウド AI ウィジェットを備えた画像ビューアーで、テキストから画像を生成するウィジェットはなく、FLUX 3 Image Klein を使うウィジェットもありません。AI モデル開示によると、Upscale は Nano Banana 2、Outfit Swap は Qwen-Image-2.1、Expand Image は FLUX.2 を使っています。

Mac で AI 画像を並べて比較するには？

Glance Preview で 2 枚を開き、左右に並べるなら Compare、同じ位置で切り替えて見るなら Slider を選びます。追加アプリなしなら、プレビュー.app のウインドウを 2 つ並べる方法もあります。

Glance Preview での比較は無料ですか？

無料です。画像の表示と比較にアカウントもクレジットも要りません。クレジットを使うのはクラウド AI ウィジェットだけです。
