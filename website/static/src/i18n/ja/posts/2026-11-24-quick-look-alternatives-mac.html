よくある質問

Finder のスペースキーで表示できる内容を増やすには？

ZIP の中身を見たいなら Folder Preview、Markdown や WebM を見たいなら Unfold が、Finder のクイックルックを拡張します。Glance Preview は画像や動画を専用のウインドウで開くアプリです。2 枚の比較は Mac 上で、AI 編集はクラウドで行います。チャットに書かれた画像のパスを開くには、文字列を選択して Glance Preview の Peek（Option + Space）を使います。

Glance Previewのメニューは日本語で使えますか？

はい。アプリの表示言語は英語・簡体字中国語・日本語・ドイツ語です。

macOS VenturaでZIPの中身を見られますか？

Folder Previewの要件はmacOS 12以降なので、Ventura（13）は対象です。Unfoldの要件は15.6以降です。

App Storeで見つけたGlanceは写真比較用ですか？

「Glance - Quick Look Code Files」はコードなどをFinderで読むための拡張機能です。写真を見比べるGlance Previewは公式サイトから入手できます。

写真をアップロードせずに修正前後を確認できますか？

できます。手元の2枚をGlance Previewで開き、並べて表示するか、スライダーで輪郭を確認します。
