チャットやターミナル、ドキュメントに ~/Downloads/hero-v2.png のようなパスが書いてあって、中身がどんな画像か知りたい。普通ならパスをコピーして Finder を開き、Shift + Command + G で貼り付ける手間がかかります。Glance Preview の Peek なら、そのテキストを選択して Option + Space を押すだけで、今いるアプリを離れずにプレビューが開きます。これは Glance チュートリアル第 3 回です。まだ未導入ならはじめての Glance ガイドからどうぞ。

※ Glance Preview のアプリ表示は英語・簡体字中国語・日本語に対応し、ドイツ語も選べます。本記事の機能名はアプリ内の英語表記で記載しています。

Peek で開けるもの

Peek は選択したテキストを読み、その中から画像リンクやファイルパスを探します。https:// のリンク、絶対パス、~/ で始まるパスなどが対象です。ローカルファイルを確実に開くには、フルパスで指定するのが最も確実です。

Glance は画像（JPEG、PNG、HEIC/HEIF、WebP、GIF、BMP、TIFF）と動画（MP4、MOV、M4V、WebM、MKV、AVI）をプレビューできます。

Peek は Glance の無料プランに含まれます。詳しくは料金ページの機能表をご覧ください。

手順 1：Peek をオンにする

Peek は任意の機能で、初期状態ではオフです。選択したテキストを読むためのシステム権限が必要になるためです。

  1. Glance の Preferences を開き、Peek をオンにします。
  2. Glance は 2 つの権限を求めます。ホットキーを検出するための「入力監視」と、選択したテキストを読むための「アクセシビリティ」です。求められたら「システム設定」→「プライバシーとセキュリティ」で両方を許可します。

権限の設定は省略してもかまいません。Glance で画像や動画を表示するだけなら権限なしで使えます。

手順 2：テキストを選択して Option + Space を押す

  1. 任意のアプリで、画像リンクやファイルパスを含むテキストを選択します。
  2. 初期設定のショートカットである Option + Space を押します。
  3. 作業中のアプリを離れずにプレビューが開きます。

何も選択していない場合は、クリップボードの内容をプレビューします。選択したテキストを公開しないアプリでは、Command + C でコピーしてからショートカットを押すと便利です。

手順 3：もっと詳しく見たいときはフルウィンドウで開く

Peek はあくまで「ちら見」用です。100% に拡大する、2 枚を比較する、AI ウィジェットを実行するには、画像を Glance のフルウィンドウで開きます。AI ツールはそちらにあります。

Peek が役立つ場面

  • AI チャットやコーディング支援ツール：ファイルを書き出すツールは ~/project/output/banner_2x.png のようなパスを返してくることがあります。それを選択して Option + Space を押せば、続ける前に画像を確認できます。
  • ターミナルの出力：スクリプトが画像を書き出したあと、パスを選択して Finder を開かずに確認できます。
  • ログ・ドキュメント・チケット：バグ報告のスクリーンショットのパスや、ドキュメント内の画像リンクも、Finder やブラウザに切り替えずに開けます。

画像を直したくなったら、フルウィンドウで開いて右クリックメニューの AI ウィジェットを使います。第 2 回のWidget Market とクレジットで、ウィジェットの追加方法と料金を説明しています。

プライバシー

選択したテキストはリンクやパスを見つけるために Mac 上で読まれ、Glance のサーバーには送られません。Web リンクの場合、プレビューはそのサイトから直接読み込みます。Preferences、ローカルの履歴、アプリのログは Mac 内の ~/Library/Application Support/Glance/ に保存されます。詳しくはプライバシーポリシー（英語）をご覧ください。

Peek が開かないとき

  • 何も起きない：Preferences で Peek がオンになっているか、「システム設定」→「プライバシーとセキュリティ」で「アクセシビリティ」と「入力監視」の両方で Glance が有効になっているか確認してください。
  • 選択が読み取られない：選択したテキストを macOS に公開しないアプリもあります。その場合は Command + C でコピーし、何も選択していない状態でショートカットを押すと、クリップボードを使って開けます。
  • 保護されたフォルダのファイルが開かない：フルパスを使うか、任意の権限であるフルディスクアクセスを許可してください。macOS が保護するファイルにだけ必要です。
  • それでも解決しない：X で {{SUPPORT_X}} に DM してください。ログファイル ~/Library/Application Support/Glance/app.log があると助かります。

よくある質問

Mac で選択したテキストのファイルパスをプレビューするには？

macOS の Quick Look は Finder で選んだファイルに働くもので、テキスト内のパスには反応しません。Glance Preview なら、Preferences で Peek をオンにし、任意のアプリでパスを選択して Option + Space を押すだけで、Finder を開かずにプレビューできます。

Peek に必要な権限は？

「入力監視」と「アクセシビリティ」の 2 つです。入力監視はホットキーの検出、アクセシビリティは選択したテキストの読み取りに使います。フルディスクアクセスは任意で、保護されたフォルダのファイルに役立ちます。Peek を使わず画像を見るだけなら権限は不要です。

Peek のショートカットは？

初期設定では Option + Space です。Peek は初期状態でオフなので、Preferences でオンにしてください。

テキストを選択していない場合は？

クリップボードの内容をプレビューします。パスをコピーしてショートカットを押せば開けます。

Peek は選択したテキストをどこかに送信しますか？

いいえ。テキストは Mac 上で読み取られます。Web リンクのプレビューはそのサイトから直接読み込みます。

Peek は無料ですか？

はい。Peek と履歴は無料プランに含まれます。AI ウィジェットはクレジットを使います。
