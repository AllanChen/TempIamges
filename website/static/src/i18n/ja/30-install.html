インストール

  1. Glance-{{VERSION}}.dmg をダウンロードし、ダブルクリックで開きます。
  2. Glance を「アプリケーション」フォルダにドラッグします。
  3. 「アプリケーション」で Glance をダブルクリックします。

初回起動がブロックされたとき

ベータ版はまだ Apple の公証を受けていないため、初回は macOS に起動をブロックされます。これは想定どおりの動作で、一度だけ許可すれば大丈夫です。

macOS 15（Sequoia）以降

  1. Glance をダブルクリックし、「開けません」と表示されたら「完了」をクリックします。
  2. 「システム設定 → プライバシーとセキュリティ」を開き、「セキュリティ」までスクロールします。
  3. 「Glance はブロックされました」の横にある「このまま開く」をクリックし、パスワードで確定します。

macOS 14 以前

「アプリケーション」で Glance を右クリックして「開く」を選び、ダイアログでもう一度「開く」をクリックします。

一度許可すれば、次回からはダブルクリックで普通に開けます。

使い始める

  • 画像や動画を開く：Finder でファイルを右クリックし、「このアプリケーションで開く → Glance」を選びます。
  • 既定のビューアにする：メニューバーで Glance → Set as Default Viewer… を選びます。
  • 2 枚の画像を選んで一緒に開くと、そのまま比較できます。
  • 画像や動画を右クリックして Widgets を選ぶと AI で処理できます。結果は元画像の隣に表示され、Compare または Slider で比較できます。

Glance は Dock とメニューバーにアイコンがある通常のアプリとして動作します。初回起動時にシステム権限もアカウントも必要ありません。14 日間の全機能試用は初回起動時に始まります。

任意機能：Peek

どのアプリでも、画像のリンクやファイルパスを含む文字列を選んでホットキー（初期設定は Option + Space）を押すとプレビューできます。Peek は任意機能で、Preferences → Enable Peek でオンにします。オンにすると「アクセシビリティ」と「入力監視」の権限を求められますが、ホットキーの検出と選択した文字列の読み取りにのみ使います。文字列が Glance のサーバーに送られることはなく、Web のリンクの場合はそのサイトから直接プレビューを読み込みます。

フィードバックとサポート

アンインストール

Glance を終了し、「アプリケーション」からゴミ箱にドラッグします。ローカルの設定とログも削除する場合は ~/Library/Application Support/Glance を削除してください。アカウントとクレジットはクラウドに保存されています。アカウントの削除は X で {{SUPPORT_X}} に DM してください。
