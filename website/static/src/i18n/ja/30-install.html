インストール

  1. Glance-{{VERSION}}.dmg をダウンロードし、ダブルクリックで開きます。
  2. Glance を「アプリケーション」フォルダにドラッグします。
  3. 「アプリケーション」で Glance をダブルクリックします。

初回起動

Glance は Apple の公証済みです。初回起動時は「インターネットからダウンロードした App です」と表示されます。「開く」をクリックしてください。

開けない場合は、「アプリケーション」から起動していることを確認し（DMG ウィンドウ内からは実行しない）、上の SHA-256 でダウンロードファイルの整合性を確認してください。

使い始める

  • 画像や動画を開く：Finder でファイルを右クリックし、「このアプリケーションで開く → Glance」を選びます。
  • 既定のビューアにする：メニューバーで Glance → Set as Default Viewer… を選びます。
  • 2 枚の画像を選んで一緒に開くと、そのまま比較できます。
  • 初めて AI で直すとき：Widget Market… を開き、Background Remover Pro（1 回 20 クレジット）などのウィジェットをインストールします。実行するとサインインを求められるので、Google またはメールのコードでサインインしてください。新規アカウントには 100 クレジットが付与されます。結果は元画像の隣に表示され、Compare または Slider で比較できます。

Glance は Dock とメニューバーにアイコンがある通常のアプリとして動作します。初回起動時にシステム権限もアカウントも必要ありません。14 日間の全機能試用は初回起動時に始まります。

任意機能：Peek

どのアプリでも、画像のリンクやファイルパスを含む文字列を選んでホットキー（初期設定は Option + Space）を押すとプレビューできます。Peek は任意機能で、Preferences → Enable Peek でオンにします。オンにすると「アクセシビリティ」と「入力監視」の権限を求められますが、ホットキーの検出と選択した文字列の読み取りにのみ使います。文字列が Glance のサーバーに送られることはなく、Web のリンクの場合はそのサイトから直接プレビューを読み込みます。

フィードバックとサポート

X で {{SUPPORT_X}} に DM してください（英語または中国語）。不具合の報告には、スクリーンショットやログファイル ~/Library/Application Support/Glance/app.log があると助かります。

アンインストール

Glance を終了し、「アプリケーション」からゴミ箱にドラッグします。ローカルの設定とログも削除する場合は ~/Library/Application Support/Glance を削除してください。アカウントとクレジットはクラウドに保存されています。アカウントの削除は Glance メニュー → Delete account から行えます。
