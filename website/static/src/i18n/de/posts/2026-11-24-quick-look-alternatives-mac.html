Zwei Fragen zu einer Bildlieferung

Ist die Rückansicht im Archiv? Bei einer ZIP mit Produktfotos reichen oft die Dateinamen und Miniaturen in Folder Preview. Liegen auch eine README und eine Videodatei im WebM-Format auf dem Mac, kann Unfold beide im Finder anzeigen. Wer dagegen in einem Quelltext eine bestimmte Zeile sucht, sollte bei Peek zuerst die Dateiendung prüfen.

Ist beim Freistellen ein Stück vom Henkel verschwunden? Liegen Original und Freisteller schon vor, öffnen Sie beide in Glance Preview und ziehen Sie den Regler über den Henkel. Dafür wird kein Bild hochgeladen. Möchten Sie den Freisteller selbst erzeugen, installieren Sie Background Remover Pro aus dem Widget Market und melden sich an. Der Auftrag läuft in der Cloud und kostet 20 Credits pro Bild.

Häufige Fragen

Welches Werkzeug erweitert die Vorschau mit der Leertaste im Finder?

Folder Preview zeigt den Inhalt von Archiven direkt in der Finder-Vorschau. Unfold ergänzt dort unter anderem Markdown und WebM. Glance Preview öffnet Bilder und Videos in einem eigenen Fenster. Dort können Sie zwei Dateien lokal vergleichen oder ein Bild mit einem Cloud-Widget bearbeiten. Steht ein Bildpfad in einer Chatnachricht, markieren Sie ihn und öffnen Sie ihn mit Peek in Glance Preview (Option + Leertaste).

Gibt es die Oberfläche von Glance Preview auf Deutsch?

Ja. Die Bedienoberfläche ist auf Japanisch, Englisch, vereinfachtem Chinesisch und Deutsch verfügbar.

Was eignet sich für Archive unter macOS Ventura?

Folder Preview führt macOS 12 als Mindestversion auf und unterstützt ZIP, TAR, GZ, 7z und RAR. Ventura erfüllt diese Voraussetzung. Unfold benötigt mindestens macOS 15.6.

Welches Programm brauche ich für eine .ipynb-Datei?

Glance - Quick Look Code Files führt Jupyter-Notebooks ausdrücklich auf. Das ist eine eigene Finder-Erweiterung. Der ähnlich benannte Bildbetrachter Glance Preview ist für die Fotoprüfung gedacht.

Brauche ich KI-Guthaben zum Vergleichen?

Nein. Zwei vorhandene Bilddateien können Sie in Glance Preview lokal nebeneinander oder mit dem Schieberegler vergleichen. Guthaben wird für Cloud-Widgets wie die Hintergrundentfernung benötigt.
