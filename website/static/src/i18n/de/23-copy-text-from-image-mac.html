Text aus einem Bild kopieren auf dem MacEine Zeile markieren oder alles lesen.

Die Vorschau von Apple kann Text mit Live Text kopieren. In Glance markieren Sie Text direkt im geöffneten Bild oder sehen sich das vollständige Erkennungsergebnis an. Die Erkennung läuft lokal auf dem Mac, ohne Pro und ohne Credits.

Glance herunterladenZu den Schritten

In Glance markieren und kopieren

  1. Bild öffnen.Zeigen Sie ein Bild mit Text im Fenster Image Inspection an und warten Sie, bis die lokale Erkennung fertig ist.
  2. Gewünschten Text markieren.Ziehen Sie über den Text im Bild, drücken Sie ⌘C und fügen Sie ihn in ein Dokument oder eine andere App ein.
  3. Für den ganzen Textwählen Sie Tools → Recognize Text. Der Ergebnisbereich zeigt den erkannten Text des aktuellen Bilds zum Prüfen und Kopieren.

Lieber mit Bordmitteln? Apples Anleitung zu Live Text in der Vorschau erklärt, wie Sie Text ohne Glance markieren und kopieren.

Wenn Text nicht erkannt wird

Ausgangsbild prüfen

Unschärfe, winzige Schrift, Schräglage, Spiegelungen und geringer Kontrast beeinträchtigen das Ergebnis. Nehmen Sie lieber ein scharfes Original als einen kleinen Screenshot.

Vollständiges Ergebnis ansehen

Lässt sich Text noch nicht markieren, prüfen Sie das Ergebnis über Tools → Recognize Text. Damit lässt sich auch ein fehlgeschlagener Scan wiederholen.

Glance bevorzugt derzeit vereinfachtes Chinesisch und Englisch, soweit macOS Vision sie unterstützt. Deutscher Text wird meist erkannt, Umlaute und ß können aber Fehler enthalten. Die verfügbaren Sprachen hängen vom System ab; prüfen Sie wichtigen Text immer am Bild.

Lokale Erkennung und Cloud-Werkzeuge

Die Texterkennung läuft auf Ihrem Mac; für OCR wird kein Bild hochgeladen. Medien werden nur hochgeladen, wenn Sie ein Cloud-KI-Widget ausführen. Details in der Datenschutzerklärung (Englisch).
