常见问题

开始前，你可能想知道

需要注册账户吗？

看图、对比、截图和文字识别无需账户。使用云端 Widget 或购买时才需要登录。

文件会被上传吗？

查看和本地工具都在 Mac 上运行。只有提交给云端 Widget 的媒体会被上传。

Pro 是订阅吗？

不是。Pro 一次买断，终身免费更新，没有自动续费。

任务失败会扣点吗？

所有失败的 Widget 任务都会自动全额退点，包括外部服务、网络和无效输入导致的失败。

试用结束后还能用什么？

看图、对比、截图、文字识别，以及按点数使用云端 Widget。其他本地工具需要 Pro。

如何付款？

在应用内选择商品，收银台会展示当前币种可用的付款方式。
