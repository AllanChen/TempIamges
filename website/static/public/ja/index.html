ひとつの流れ

見る → その場で直す → 比べて確かめる

Web ツール、ダウンロードフォルダ、別のビューアを行き来する必要はありません。作業はひとつのウインドウで完結します。

01

細部まで見る

macOS ネイティブの画像・動画ビューア。拡大縮小、パン、フォルダ内の連続表示、動画再生とフレームの切り出しに対応。デフォルトのビューアに設定して Finder から直接開けます。

  • PNG、JPEG、HEIC、WebP、AVIF、GIF、SVG、TIFF など
  • MP4、MOV、M4V、WebM、MKV、AVI の動画
02

気になったら、その場で AI

右クリックメニューから Widget を選んで、画像や動画を高解像度化、拡張、背景除去などで加工できます。クラウド Widget はサインインが必要で、クレジットを消費する場合があり、送信したメディアは処理のためにアップロードされます。メニューに消費クレジットが表示され、結果は「ダウンロード/Glance」に保存されます。

  • タスクはバックグラウンドで実行され、その間も閲覧を続けられます
  • システム側の失敗やキューのタイムアウトでは、クレジットが自動で返還されます
03

元の画像と結果を比べる

元の画像と結果を並べて表示したり、スライダーで切り替えたりできます。何が変わったかを確かめてから使えます。

よくある質問

アカウントは必要ですか？

いいえ。表示、比較、キャプチャはアカウントなしで使えます。クラウド AI Widget を初めて使うときや購入するときだけ、Google またはメールのコードでサインインします。

ファイルはアップロードされますか？

いいえ。表示とローカルツールは Mac 上で動作します。クラウド Widget を実行したときだけ、選択した画像や動画が処理のためにアップロードされます。

Pro はサブスクリプションですか？

いいえ。Pro は買い切りで、アップデートはずっと無料です。更新や自動課金は一切ありません。

タスクが失敗したらクレジットは消費されますか？

システム側の失敗、30 分を超える待機、または処理開始前のキャンセルの場合、クレジットは自動で全額返還されます。処理開始後に自分でキャンセルした場合は返還されません。

トライアル終了後は何が使えますか？

画像と動画の表示、比較、キャプチャ、画像内の文字認識とコピー、クレジットでの AI Widget 利用は引き続き無料です。フォーマット変換、圧縮、書き出し、画像のコピー、編集、Base64 には Pro が必要です。ファイル、結果、クレジットはそのまま残ります。
