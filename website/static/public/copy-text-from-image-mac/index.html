Glance 使用指南 · 图片文字

在 Mac 上复制图片里的文字直接选中，或查看完整识别结果。

macOS 自带的「预览」可用实况文本复制图片文字。使用 Glance 时，也可以在图片窗口直接选中复制，或打开完整识别结果。Glance 的这项识别在本机运行，无需 Pro 和点数。

下载 Glance查看步骤

在 Glance 中选取并复制

  1. 打开图片。在 Glance 的 Image Inspection 窗口查看含文字的图片，等待本机文字识别完成。
  2. 选中所需文字。在图片上拖选文字，按 ⌘C，然后粘贴到文档或其他 App。
  3. 需要完整结果时，从「工具」菜单选择「识别文字」。侧边结果窗口会显示这张图片识别出的全部文字，便于整体查看和复制。

只想用 macOS 自带功能？Apple 的预览实况文本指南说明了如何直接在「预览」中选中并复制，不需要安装 Glance。

识别不准确时

先检查原图

模糊、小字、倾斜、反光和低对比度都可能影响结果。尽量使用清晰原图，而不是低分辨率截图。

再查看完整结果

如果图片上的文字暂时无法选中，打开「工具 → 识别文字」查看是否已识别。菜单操作也可重试一次失败的扫描。

Glance 目前优先使用系统支持的简体中文和英语识别。具体可识别语言取决于 macOS 的 Vision 支持情况；识别结果可能有错误，重要内容请对照原图核实。

本地识别与云端工具

图片文字识别在 Mac 本机完成，不会为此上传图片。只有你主动运行云端 AI Widget，所选媒体才会上传处理。查看隐私政策了解详情。
