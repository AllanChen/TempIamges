Glance guide · Image text

Copy text from an image on MacSelect a line or read the full result.

Apple Preview can copy text with Live Text. In Glance, you can select text directly in an open image or view the full recognition result. Glance runs this recognition on your Mac without Pro or credits.

Download GlanceSee the steps

Select and copy in Glance

  1. Open the image.View an image with text in Glance's Image Inspection window and allow local recognition to finish.
  2. Select what you need.Drag across the text in the image, press ⌘C, then paste it into a document or another app.
  3. For the full result,choose Tools → Recognize Text. The result panel shows the text recognized from the current image for review and copying.

Prefer a built-in option? Apple's Live Text guide for Preview explains how to select and copy text without installing Glance.

When recognition misses text

Check the source image

Blur, tiny type, skew, glare, and low contrast can affect the result. Try a clear original rather than a small screenshot.

Review the full result

If text is not selectable yet, open Tools → Recognize Text to check the result. This action can also retry a failed scan.

Glance currently prefers Simplified Chinese and English when supported by macOS Vision. Available languages depend on the system, and recognition can make mistakes. Verify important text against the image.

Local recognition and cloud tools

Image text recognition runs on your Mac and does not upload the image for OCR. Selected media is uploaded only when you run a cloud AI Widget. Read the privacy policy for details.
