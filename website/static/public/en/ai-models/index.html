AI Model Disclosure

AI models and capabilities

This public page describes Glance cloud Widget capabilities, underlying models and processing services. No account, download or purchase is required to read it.

Updated: October 22, 2026

Which AI capabilities does Glance offer?

CapabilityCurrent scope
Text to imageNo current Widget generates an image from text alone.
Image to image and image editingRequires an input image. Includes regeneration, upscaling, outfit changes, outpainting, watermark removal and background removal. Regeneration, outfit changes and outpainting create new image content.
Image to videoNo current Widget generates a video from a still image.
Video inpaintingVideo Watermark Removal processes an existing video and returns an edited video. It does not generate video from a still image.
Image understandingImage to Prompt describes an input image in text; it does not generate images.

Media processing and use

When you run a cloud AI Widget, the selected media is uploaded to Glance and processed through RunningHub. Image Hosting stores and shares files without using an AI model. Glance does not use your media to train models.

Upload only content you own or have permission to process. Obtain the subject’s consent before using their photo for an outfit change. See our Privacy Policy, Terms of Service and Acceptable Use Policy. See Pricing for prices.
