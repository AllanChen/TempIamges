安装

  1. 下载 Glance-1.0.2.dmg，双击打开。
  2. 把 Glance 拖到「应用程序」文件夹。
  3. 在「应用程序」里双击 Glance。

首次打开

Glance 已通过 Apple 公证。第一次打开时，macOS 会提示它是从互联网下载的 App，点「打开」即可。

如果提示无法打开，请先确认已把 Glance 拖进「应用程序」并从那里打开，不要直接在 DMG 窗口里运行；也可以用上方的 SHA-256 核对下载文件是否完整。

开始使用

  • 直接打开图片或视频：在 Finder 里右键文件，选择「打开方式 → Glance」。
  • 设为默认看图器：菜单栏选择「Glance → 设为默认看图器…」。
  • 选中两张图片一起打开，直接进入对比。
  • 右键图片或视频，选择「Widgets」用 AI 处理。完成后结果出现在原图旁边，点 Compare 或 Slider 对比效果。

Glance 作为普通 App 运行，有 Dock 图标，也有菜单栏图标。首次打开不需要任何系统权限，也不需要账户。首次启动即开始 14 天完整试用。

可选：Peek（选中文本秒开预览）

在任意 App 里选中一段包含图片链接或文件路径的文字，按下热键（默认 Option + Space）就能预览；没有选中文字时，Peek 会预览剪贴板内容。这是可选功能，默认关闭，在「偏好设置 → 启用 Peek」里打开。

打开 Peek 后，Glance 会引导你授予「辅助功能」权限，它只用于识别热键和读取你选中的文字。已授予「辅助功能」时，「输入监控」无需单独授权。「完全磁盘访问」是可选项，只在打开受系统保护的文件时需要。你可以跳过权限设置，查看图片和视频不受影响。

选中的文字不会发送到 Glance 服务器；如果是网络链接，Glance 会直接从该网站加载预览。

反馈与问题

请发邮件至 support@glancepreview.com，目标在 1–2 个工作日内回复。请提供复现步骤、预期与实际结果、App 版本和 build、macOS 与芯片架构，并按需附上截图、订单号或 Widget 任务 ID。

新版 App 可通过「帮助 → 报告问题」生成邮件模板，通过「显示日志」或「导出诊断」准备附件；旧版可手动找到 ~/Library/Application Support/Glance/app.log。诊断只在本机导出，不会自动上传，查看并确认内容后再发送。

日志、邮箱、完整订单信息和兑换码请只通过私密邮件提供，不要贴在公开帖子或回复里。

兑换 Pro

登录后打开账户页，选择「兑换 Pro」并输入兑换码。每个码只能兑换到一个账户，不赠送 AI 点数，也不产生付款订单。已有有效 Pro 时不会覆盖授权或消耗新码。终身码提供终身 Pro；一年码从兑换日起计算一年，到期自动回到免费版，离线授权也不能超过到期日。兑换截止日与兑换后的 Pro 到期日是两回事。

卸载

退出 Glance，把它从「应用程序」拖到废纸篓。如需同时删除本地设置与日志，删除 ~/Library/Application Support/Glance。账户与点数保存在云端，如需删除账户，请使用 Glance 菜单 → 删除账户。
