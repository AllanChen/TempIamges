安装

  1. 下载 Glance-1.0.0-beta.1.dmg，双击打开。
  2. 把 Glance 拖到「应用程序」文件夹。
  3. 在「应用程序」里双击 Glance。

首次打开被拦截怎么办

这个安装包还没有经过 Apple 公证，macOS 第一次打开时会拦截，这是正常的，只需放行一次。

macOS 15（Sequoia）及更新版本

  1. 双击 Glance，看到「无法打开」提示后点「完成」。
  2. 打开「系统设置 → 隐私与安全性」，往下滚到「安全性」。
  3. 在「已阻止 Glance 打开」旁边点「仍要打开」，输入密码确认。

macOS 14 及更早版本

在「应用程序」里右键 Glance，选择「打开」，在弹窗里再点一次「打开」。

放行一次之后，以后双击就能正常打开。

开始使用

  • 直接打开图片或视频：在 Finder 里右键文件，选择「打开方式 → Glance」。
  • 设为默认看图器：菜单栏选择「Glance → 设为默认看图器…」。
  • 选中两张图片一起打开，直接进入对比。
  • 右键图片或视频，选择「Widgets」用 AI 处理。完成后结果出现在原图旁边，点 Compare 或 Slider 对比效果。

Glance 作为普通 App 运行，有 Dock 图标，也有菜单栏图标。首次打开不需要任何系统权限，也不需要账户。首次启动即开始 14 天完整试用。

可选：Peek（选中文本秒开预览）

在任意 App 里选中一段包含图片链接或文件路径的文字，按下热键（默认 Option + Space）就能预览；没有选中文字时，Peek 会预览剪贴板内容。这是可选功能，默认关闭，在「偏好设置 → 启用 Peek」里打开。

打开 Peek 后，Glance 会引导你授予「辅助功能」权限，它只用于识别热键和读取你选中的文字。已授予「辅助功能」时，「输入监控」无需单独授权。「完全磁盘访问」是可选项，只在打开受系统保护的文件时需要。你可以跳过权限设置，查看图片和视频不受影响。

选中的文字不会发送到 Glance 服务器；如果是网络链接，Glance 会直接从该网站加载预览。

退出 Glance，把它从「应用程序」拖到废纸篓。如需同时删除本地设置与日志，删除 ~/Library/Application Support/Glance。账户与点数保存在云端，如需删除账户，请使用 Glance 菜单 → 删除账户。
