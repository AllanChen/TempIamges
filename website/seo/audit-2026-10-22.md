# Glance SEO 首轮审计

日期：2026-10-22。对象：`https://glancepreview.com/`。

本报告保留发布前发现。当天后续已完成 S01、S02、S03、S06 的修复和上线，当前状态见 [发布记录](releases/2026-10-22.md)。

## 结论

官网可访问，主要页面已有静态正文、canonical、description 和下载入口。第一阶段应把现有内容整理成语言明确、搜索需求明确的页面，再补充功能教程。

优先事项：独立语言 URL、首页定位与标题、支付返回页索引规则、转化与索引基线。没有足够证据给网站打 SEO 分数，也没有依据声称网站“未被 Google 收录”。

## 方法与边界

- 检查 sitemap 中全部 9 个 URL，以及 robots.txt、域名跳转、一个不存在的 URL 和下载响应；共记录 17 个请求入口。
- 使用公共 HTTP 请求读取响应头与原始 HTML，并比对本地 `website/static/` 源码。
- 下载仅发 HEAD 请求；没有运行 App、操作其 UI 或触发付款。
- 没有登录 Search Console，没有进行浏览器渲染检查、移动端布局检查或 Core Web Vitals 实测。
- 网络搜索的地区和设备未固定，结果仅用于发现主题与参考页面，不代表指定市场的 Google 排名。
- 首次网页读取工具无法打开官网，但随后直接 HTTP 请求成功；不能把工具失败当作网站故障。

完整数据：[HTTP 审计 JSON](evidence/2026-10-22-http-audit.json)。

## 发现与建议

### S01 · 高优先级：中英文没有独立 URL

**证据：** 主页面原始 HTML 为 `lang="zh-CN"`，中英文正文同时存在；`site.js` 根据浏览器语言或本地存储切换可见内容与 `document.title`。未发现语言 alternate 链接。

**影响：** 英文页面没有可独立引用、提交和观察表现的地址；搜索引擎看到的语言版本依赖渲染状态。这里的问题是语言 URL 和内容的一致性，不是把多个 H1 简单视为处罚信号。

**建议：** 若英文优先，先新增 `/en/`、`/en/install/`、`/en/widgets/`、`/en/pricing/`，初始 HTML 直接输出对应语言标题与正文。现有 URL 继续服务中文，逐步整理为单一语言。语言切换使用真实链接；每个语言页 self-canonical，并为存在的对应页设置双向 `hreflang`。不因浏览器语言强制跳走。

**验收：** 不执行 JS 也能读到正确语言；英文和中文可单独访问；canonical 不把英文指回中文；语言链接成对且目标返回 200。此做法依据 [Google 多语言网站指南](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites) 和 [本地化版本标注说明](https://developers.google.com/search/docs/specialty/international/localized-versions)。

### S02 · 高优先级：首页标题没有直接表达产品类别

**证据：** [线上首页](https://glancepreview.com/) 原始标题是 `Glance · AI 时代的 Preview`，英文脚本标题是 `Glance · The Preview for the AI era`。正文已有 macOS 看图与视频信息，但标题主要是品牌口号。

**建议：** 英文页 title 草案为 `Glance — Mac Image Viewer with AI Tools & Comparison`，H1 明确图片、视频和 Mac。口号可以作为副文案。让下载、免费查看、本地处理与云端 Widget 的区别更容易理解。

**验收：** title、H1、description 和首屏表达同一产品用途；不使用“最快”“最好”或未证实的独有功能宣称。草稿见 [英文首页文案](content/homepage-en.md)。这是相关性与表达的改进建议，不保证具体排名。

### S03 · 中优先级、应先修：支付返回页索引信号冲突

**线上证据：** [sitemap.xml](https://glancepreview.com/sitemap.xml) 包含 `/pay/return/`；[robots.txt](https://glancepreview.com/robots.txt) 禁止抓取 `/pay/`；支付返回页返回 200，未发现 meta 或响应头 `noindex`。

**源码原因：** `src/pages/50-pay-return.html` 与 `50-payment-return.html` 定义同一路径。前者有 `noindex: true`，后者没有；按文件名排序构建时后者覆盖前者，并把 URL 加入 sitemap。

**建议：** 保留当前支付回调逻辑，只保留一个生效页面定义并标注 `noindex`；构建器遇到重复路径直接报错；从 sitemap 移除支付页。针对公开返回页允许抓取，以便搜索引擎看到 `noindex`，其余支付路径按用途处理。

**验收：** 支付返回行为保持一致；带与不带查询参数的返回页均携带 `noindex`；sitemap 不含返回页；robots 允许读取该指令。不能依靠 robots 禁止抓取来保证不收录，见 [Google noindex 说明](https://developers.google.com/search/docs/crawling-indexing/block-indexing)。

### S04 · 高优先级：具体使用需求缺少独立落地页

**证据：** 当前 sitemap 的产品页面为首页、价格、安装和 Widget；没有图片对比、图片文字识别等专门页面。这些功能已在首页出现。

**建议：** 第一批内容围绕图片对比教程与图片文字复制教程，提供真实操作步骤、示例结果、限制和下载入口。先做少量完整页面，避免按关键词同义词批量复制页面。

**验收：** 每页回答一个明确需求，有从首页或相关文章进入的链接；同一意图的近义词合并；页面内容与发行版本一致。内容顺序及资料要求见 [执行计划](plan.md)。

### S05 · 中优先级：部分商业内容依赖 JavaScript 与 API

**证据：** `/widgets/` 的实时目录容器在原始 HTML 中是 skeleton；下方模型说明表已经是静态正文，不能称整个页面没有内容。`/pricing/` 的套餐区域也由 JS 填充，fallback 数据存在于 JSON 而非可见的套餐 HTML。

**建议：** 提供构建时生成的目录与套餐可读快照，前端再更新最新数据；定价快照应标注更新时间并与实际计费来源一致。后续只为有完整说明的 Widget 建独立页面。

**验收：** 不执行 JS 也能读到主要工具名称、用途与套餐信息；API 不可用时页面仍有内容；实时数据更新不破坏已有链接。Google 可以执行 JS，但仍有处理阶段和限制，见 [JavaScript SEO 基础](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics)。

### S06 · 中优先级：站点地图修改时间统一硬编码

**证据：** 9 个 sitemap 条目的 `lastmod` 都是 `2026-10-16`，生成器使用全局 `UPDATED`。

**建议：** 改成每页实际内容更新日期，或无法维护时省略该可选字段；不要把每次构建日期写成所有页面修改日期。

**验收：** 修改一个页面不自动改变其他页面的 lastmod；日期有内容变更记录支撑。参考 [Google sitemap 指南](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap)。

### S07 · 高优先级：尚未建立可核验的效果基线

**证据范围：** 本轮未获得 Search Console 或分析平台数据；源码与所取 HTML 未发现常见统计脚本。这不排除已有 Cloudflare 后台统计或其他服务端统计。

**建议：** 确认域名资产和现有工具，记录自然搜索曝光、点击、落地页及下载点击。将“下载点击”与“下载完成”“安装成功”“首次使用”分开计量。

**验收：** 有按日期、页面和语言读取的基线，事件定义明确。公开搜索 `"glancepreview.com"` 本次没有结果，只能记为一次工具观察，不能据此断定 Google 零收录或零流量。

## 暂不下结论的事项

- Core Web Vitals、移动布局、实际 JS 渲染：未测量。
- Google 索引状态与收录 canonical：需要 Search Console 的 URL 检查。
- 关键词搜索量、竞争难度、预估转化率：没有工具数据，不填猜测数字。
- 主要页面没有发现 JSON-LD；这不是抓取阻断项。可在基本页面完善后补充真实的软件信息，不编造评分或承诺富结果展示。
- 预览部署域名是否开放索引：本地 middleware 对 `.pages.dev` 例外，但没有核对实际部署地址与响应，保留为待查项。
